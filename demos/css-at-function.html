CSS @function

Reusable custom functions with arguments, defaults, type-checking, and a result descriptor — pure CSS, zero JavaScript, zero preprocessor.

CSS Functions & Mixins L1 Chrome 139+ Edge 139+ Opera 123+ Safari TP (in development) Firefox: pending

1 Negate any value

Define a function once, call it everywhere. Default-value support means the function stays terse at the call site.

/* Define once */
@function --negate(--value) {
  result: calc(-1 * var(--value));
}

/* Use anywhere */
html {
  --gap: 1.5rem;
  padding: --negate(var(--gap));
}

2 Fluid typography that reads like copy

Wrap clamp() math in a named function. Designers and devs both read --fluid-type(24px, 36px) in 2 seconds — much clearer than the raw clamp() it expands to.

@function --fluid-type(--font-min, --font-max, --type: 'header') {
  --scalar: if(style(--type: 'header'): 4vw; style(--type: 'copy'): 0.5vw);
  result: clamp(var(--font-min), var(--scalar) + var(--font-min), var(--font-max));
}

h1 { font-size: --fluid-type(24px, 36px); }
p  { font-size: --fluid-type(16px, 20px, 'copy'); }

Resize the viewport

This paragraph scales at half the rate of the heading — exactly what you want when you don't want your body copy to feel shouty on a 27" monitor. Try it: drag the window narrow and watch both shrink.

3 One-line opacity variants for any color

Replaces the legacy color-mix(... transparent) dance with relative color syntax — wrapped in a function for ergonomics.

@function --alpha(--color, --opacity: 1) {
  result: rgb(from var(--color) r g b / var(--opacity));
}

:root {
  --brand: #6c5ce7;
  --brand-soft: --alpha(var(--brand), 0.2);
}

4 Conditional border-radius (no media queries)

When an element approaches the viewport edge, drop the rounded corners automatically. This is the "Facebook trick" turned into a reusable function with a sane default.

@function --conditional-radius(--radius, --edge-dist: 4px) {
  result: clamp(0px, ((100vw - var(--edge-dist)) - 100%) * 1e5, var(--radius));
}

.card { border-radius: --conditional-radius(1rem); }
Stays rounded at desktop · flattens at the edge

5 Responsive sidebar (one line, no media query)

Use @media INSIDE the function body to branch the result. The grid template then reads as plain English: "sidebar layout, default 20ch".

@function --layout-sidebar(--sidebar-width: 20ch) {
  result: 1fr;

  @media (width > 640px) {
    result: var(--sidebar-width) auto;
  }
}

.layout {
  display: grid;
  grid-template-columns: --layout-sidebar();  /* uses 20ch default */
}

6 Theme-aware functions (light-dark upgrade)

Native light-dark() only works on color values. Wrap it in a function and you can pass anything: spacing, radii, shadows, gradients.

@function --light-dark(--light, --dark) {
  result: if(
    style(--scheme: dark): var(--dark);
    else: var(--light)
  );
}

/* Theme toggle sets --scheme on :root or html */
.demo-card {
  --scheme: light;
  padding: --light-dark(2rem, 2.5rem);
  border-radius: --light-dark(16px, 8px);
  box-shadow: --light-dark(0 2px 8px rgba(0,0,0,0.08), 0 4px 16px rgba(0,0,0,0.4));
}
Padding, radius & shadow all swap between themes — not just colors.

7 Why this matters for design systems

Before @function, you needed a preprocessor (Sass mixins) or a JS build step (style-dictionary, vanilla-extract) for any of the above. Now it's a single CSS file.

Use caseBeforeWith @function
Fluid type clamp(16px, 0.5vw + 16px, 20px) --fluid-type(16px, 20px, 'copy')
Color tints color-mix(in srgb, var(--brand) 20%, transparent) --alpha(var(--brand), 0.2)
Edge-aware radius Hand-written clamp expression + media query --conditional-radius(1rem)
Responsive sidebar Media query on the consumer + duplicated template-columns grid-template-columns: --layout-sidebar()
Theme-aware non-color tokens JS theme manager + class swap --light-dark(2rem, 2.5rem)
Browser support note (June 2026): Chrome 139+ / Edge 139+ / Opera 123+ ship @function with the result descriptor, type checking, default values, and per-parameter data types. Safari is in development (Tech Preview). Firefox: not yet. Spec: CSS Functions and Mixins Module Level 1 (W3C Working Draft). Graceful degradation: in unsupported browsers, the function becomes invalid at computed-value time and falls back to the next declared value.
