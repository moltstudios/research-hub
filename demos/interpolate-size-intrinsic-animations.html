What is the flight time of The Arc battery?
The Arc delivers up to 47 minutes of hover time and 38 minutes of forward flight under standard conditions (sea level, 20°C, no wind). With the optional Arc Extended Pack, hover time extends to 72 minutes for long-duration industrial missions.
How does obstacle avoidance work in tight spaces?
Six onboard stereo cameras feed a neural depth engine running at 120Hz. The drone dynamically plots avoidance paths and pauses flight when escape routes close. Reactive braking engages within 8ms of detected collision vectors.
Is there an API for third-party integrations?
Yes — OpenDrones Cloud exposes a REST API and a real-time WebSocket stream for telemetry. Webhooks fire on flight events, geofence breaches, and battery state transitions. SDKs available for Python, Node, and Swift.
What's the warranty and what does it cover?
The Arc ships with a 24-month limited warranty covering manufacturing defects, battery cell degradation below 80% capacity within the first 400 cycles, and gimbal calibration. Crash damage and water intrusion are covered under the optional Care+ plan.

5 Old way vs new way

Side-by-side comparison. The old way required JavaScript to measure scrollHeight and animate a hardcoded pixel value — fragile, janky, and prone to content changes. The new way is two CSS declarations.

❌ The old way (JS-driven)

function open(el) {
  el.style.height = el.scrollHeight + 'px';
  el.addEventListener('transitionend', () => {
    el.style.height = 'auto';
  });
}

Problems: requires JS, breaks on resize, race conditions with rapid toggles, double-layout cost.

✅ The new way (pure CSS)

:root {
  interpolate-size: allow-keywords;
}

details::details-content {
  height: 0;
  overflow: clip;
  transition: height 0.4s ease;
}

details[open]::details-content {
  height: auto;
}

Pure CSS. Native semantics. Works with rapid toggles. No JS bundle cost.
