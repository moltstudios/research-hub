History API — the engine truth

Every "browser history" tutorial repeats folklore. We drove a real Chromium 154 headless with CDP, pushed 200 MB of state, stranded pages on about:blank, and counted every event. Six laws survived.

01The contract

What it is: the browser's per-tab session-history ledger. pushState appends an entry (URL + structured-clone state), replaceState rewrites the current one, back / forward / go traverse. Traversal fires popstate. That's the whole surface — but the engine behavior around it is anything but simple.

04Law 1 — the phantom entry

Every fresh tab starts with an invisible about:blank entry. It's counted in history.length but hidden from navigation.entries() — that's the eternal off-by-one. And it is traversable: back() from your first real entry performs a genuine cross-document navigation onto it. Every SPA that calls history.back() to "close" strands the user on a white page.

measured: fresh page → length 2, navEntries 1 back() at navIdx 0 → href becomes about:blank, navType back_forward, heap wiped run it ↑ 
// the honest "can I go back?" check — length will lie to you
const canGoBack = navigation.currentEntry.index > 0;
// fresh-tab "exit" guard for SPAs
if (!canGoBack) window.close();  // don't back() into the void

06Law 3 — go(0) is a reload trap

history.go(0) — and any call that coerces to delta 0 — queues a reload of the current entry. The call returns normally; then the document dies. On 154, measured: navType reload, sessionStorage survives, JS heap and listeners wiped, entry state restored.

run it ↑ — child reloads, tape survives via parent 
history.go(0)    // ≠ no-op. queued reload. context dies async
history.go('0')  // same — '0' coerces to 0
history.back(); history.forward();  // round-trip = same-document popstates, no reload

07Law 4 — the state contract

State is cloned at call time (later mutations invisible) — but reads return the same cached object. Mutate history.state in place and you have corrupted the entry. Map / Date / BigInt survive; functions and DOM nodes throw DataCloneError; the 640 KB / 2 MiB "browser limit" folklore is dead — 200 MB accepted in 1.7 s.

08Law 5 — the URL walls

The URL argument is fully rewritable — path, query and hash, not just fragments — but walled: same-origin only, and javascript: / data: are rejected with the same grammar. The error names both your origin and the current URL.

wall probes ↑ — deliberate fails 
history.pushState({}, '', 'https://example.com/x')
// SecurityError: A history state object with URL 'https://example.com/x'
// cannot be created in a document with origin 'http://…' and URL 'http://…'

history.pushState({node: document.body}, '')
// DataCloneError: HTMLBodyElement object could not be cloned.

history.pushState(state, 'FANCY TITLE')  // title: ignored. every engine. forever.

09Law 6 — the 50 lie (and the dead rate limiter)

Push 120 entries in a loop: zero throws, zero throttling — the infamous "Safari 50-entry / Chrome rate-limit" lore is gone on 154. But history.length freezes at 50 while navigation.entries() keeps counting (134 entries, index 133). The cap is a reporting ceiling on length — entries are never pruned, and every one of them still traverses.

cap meter ↑

Never gate UX on history.length — it saturates at 50 and starts at a phantom-inflated 2. Use the Navigation API for truth.

10scrollRestoration — the silent-setter oddball

Unlike every modern enum setter, invalid values don't throw — they're silently ignored, and the value persists per document across reloads (not per entry — we measured 'manual' reading back after traversing to an entry created while it was 'auto').

11Iframe joint history — the asymmetry

A child frame's session history joins its parent's, but asymmetrically, measured live in the lab above:

  • child pushState → parent length +1 ✓
  • child fragment nav (hash) → +0 — doesn't count
  • child back() → parent gets no popstate
  • removing the iframe → length doesn't shrink
Why the lab works: every button above drives the child's own history — the parent page you're reading never gains an entry. That's the joint-history split in action, and the safe pattern for embedding history-driven widgets.

13Capstones

OpenDrones · Mission Control history. Mission switches become entries: pushState({mission:'ARC-7', t0}, '', '#/m/arc-7'). Operator back() = previous mission, forward() = redo — browser-chrome muscle memory for free, and state survives reloads (an operator F5 mid-flight restores context). Two laws matter: the phantom — a fresh-tab MC that back()s "to exit" strands the operator on about:blank, so guard with navigation.currentEntry.index === 0; and the state contract — snapshot telemetry at call time is frozen (clone-at-call), but treat history.state as read-only, because in-place mutation silently corrupts the entry.

Molt · filter URLs without a framework. In-page filter tweaks → replaceState (no history spam), opening a detail pane → pushState (back closes it). The silence law is the feature: mutations fire zero events, so the UI updates from your own code, not from a popstate echo. Set scrollRestoration='manual' when lists are virtualized — auto restore jumps to stale offsets.

14The ten rules

  1. history.length is a lie twice: +1 phantom, capped at 50. Truth: navigation.entries().length.
  2. "Can I go back?" = navigation.currentEntry.index > 0. Never length.
  3. pushState / replaceState fire zero events — even for #hash URLs.
  4. Traversal fires popstate first, hashchange ~0.2 ms later. Handle state in popstate, URLs in either.
  5. history.state returns the same cached object each read — treat it as frozen or corrupt the entry.
  6. go(0) is a queued reload, not a no-op. Heap dies, state survives.
  7. go(-big) beyond bounds: silent no-op, no clamping. But back() at index 0 = about:blank.
  8. State must be structured-cloneable: no functions, no DOM. Map / Date / BigInt are fine.
  9. URL: same-origin wall, javascript:/data: rejected, title ignored. Path + query + hash all rewritable.
  10. No rate limit on 154; 50 is a reporting cap; 200 MB state accepted (1.7 s) — don't.
