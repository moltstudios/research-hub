Code: Variants & Orchestration

Variants let you define animation states and orchestrate staggered transitions across component trees.

React + Motion
import { motion } from "motion/react";

// Define variant states
const containerVariants = {
  hidden: { opacity: 0 },
  visible: {
    opacity: 1,
    transition: { staggerChildren: 0.08 }
  }
};

const itemVariants = {
  hidden: { y: 24, opacity: 0 },
  visible: { y: 0, opacity: 1,
    transition: { type: "spring", stiffness: 300, damping: 24 }
  }
};

export default function Grid() {
  return (
    <motion.div
      variants={containerVariants}
      initial="hidden"
      animate="visible"
    >
      {items.map((item) => (
        <motion.div key{item.id} variants={itemVariants} />
      ))}
    </motion.div>
  );
}

Code: AnimatePresence & MotionValues

AnimatePresence triggers exit animations when components unmount. useMotionValue creates reactive values that bypass React renders.

AnimatePresence
import { motion, AnimatePresence } from "motion/react";

export default function TodoList({ items }) {
  return (
    <AnimatePresence mode="popLayout">
      {items.map((item) => (
        <motion.div
          key={item.id}
          initial={{ opacity: 0, scale: 0.8 }}
          animate={{ opacity: 1, scale: 1 }}
          exit={{ opacity: 0, scale: 0.8, y: -20 }}
          transition={{ type: "spring", stiffness: 400 }}
          layout
        />
      ))}
    </AnimatePresence>
  );
}
useMotionValue + useScroll
import { motion, useMotionValue, useScroll, useTransform } from "motion/react";

export default function ScrollProgress() {
  const { scrollYProgress } = useScroll();
  const width = useTransform(scrollYProgress, [0, 1], ["0%", "100%"]);
  const x = useMotionValue(0);

  return (
    <motion.div style={{ width }} />
  );
}

Code: Shared Layout Animations (layoutId)

layoutId enables hero transitions — when two components share a layoutId in different renders, Motion automatically animates between their positions.

// List → Detail hero transition
export default function Gallery() {
  const [selected, setSelected] = useState(null);

  return (
    <>
      {!selected ? (
        {items.map((item) => (
          <motion.img
            key={item.id}
            layoutId={`photo-${item.id}`}
            onClick={() => setSelected(item)}
          />
        ))}
      ) : (
        <motion.img
          layoutId={`photo-${selected.id}`}
          onClick={() => setSelected(null)}
        />
      )}
    </>
  );
}

Performance Best Practices

Keep animations buttery smooth with these proven patterns.

⚡

Transform-Only Animations

Animate transform and opacity only — they're GPU-composited and skip layout/paint. Avoid animating width, height, top, left directly.

🧠

will-change Sparingly

Add will-change: transform to elements about to animate, then remove it. Don't leave it on permanently — it wastes GPU memory.

♿

Respect prefers-reduced-motion

Wrap animations in a reduced-motion check. Motion supports useReducedMotion() — use it to provide instant-state fallbacks for users who need them.

🎯

Layout Animations = FLIP

Motion's layout prop uses FLIP (First, Last, Invert, Play). It measures before/after positions and applies transform-based animations — zero layout thrashing.

📦

Lazy Mount with useInView

Don't animate off-screen elements. Use useInView to trigger animations only when elements enter the viewport — saves CPU and feels intentional.

🔄

MotionValues Over State

useMotionValue bypasses React's render cycle. For drag/scroll-linked values, MotionValues are 10x faster than setState on every frame.
