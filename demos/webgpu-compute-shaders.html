The Kernel (WGSL)

This shader runs N×M times per frame — once per particle, in parallel
// Each invocation = one particle. global_id is unique per parallel thread.
@group(0) @binding(0) var<storage, read_write> particles: array<Particle>;
@group(0) @binding(1) var<uniform> params: SimParams;

struct Particle { pos: vec2<f32>, vel: vec2<f32>, color: vec4<f32>; }
struct SimParams { dt: f32, gravity: f32, damping: f32, time: f32; }

@compute @workgroup_size(64)
fn main(@builtin(global_invocation_id) gid: vec3<u32>) {
  let i = gid.x;
  if (i >= arrayLength(&particles)) { return; }

  var p = particles[i];

  // Gravity toward center
  let toCenter = -p.pos * 0.002;
  p.vel += toCenter * params.gravity * params.dt;

  // Damping
  p.vel *= params.damping;

  // Integrate
  p.pos += p.vel * params.dt;

  // Wrap bounds
  let r = 0.9;
  if (length(p.pos) > r) {
    p.pos = normalize(p.pos) * r;
    p.vel *= -0.8;
  }

  particles[i] = p;
}

Core Concepts

The API primitives that make compute possible
⚡
Compute Pipeline
Pre-compiled kernel + bind group layout. Created once, dispatched many times.
📦
SSBO (Storage Buffer)
Shader Storage Buffer Object — read/write GPU memory, zero-copy from JS.
🎛️
Uniform Buffer
Small, fast, read-only — pass config (dt, params) from CPU to GPU.
🔗
Bind Group
Resource slots — tells the kernel which buffers/textures it can see.
🧵
Workgroups
Threads execute in groups of N (e.g. 64). dispatchWorkgroups(N/64, 1, 1).
⏱️
Timestamp Queries
Measure exact GPU time with writeTimestamp / GPU timestamp feature.

The Dispatch (JS side)

How JavaScript launches the kernel
const commandEncoder = device.createCommandEncoder();
const pass = commandEncoder.beginComputePass({ timestampWrites });

pass.setPipeline(computePipeline);
pass.setBindGroup(0, bindGroup);
pass.dispatchWorkgroups(Math.ceil(particleCount / 64));  // one thread per particle

pass.end();
device.queue.submit([commandEncoder.finish()]);
