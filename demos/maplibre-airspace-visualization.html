02What Is MapLibre GL JS — And Why It Wins for OpenDrones

MapLibre GL JS is the open-source fork of Mapbox GL JS created in December 2020 when Mapbox relicensed their library from BSD to a proprietary license. The MapLibre team picked up where Mapbox left off, added 3D terrain, custom layer hooks, and a fully open ecosystem. Today it's a production-grade alternative used by Wikipedia, Foursquare, AWS Location Service, Meta, and the entire OpenStreetMap ecosystem.

$

Zero Per-Tile Fees

Mapbox charges $5–30K/yr for production tile loads. MapLibre + OpenFreeMap (or self-hosted PMTiles) is free forever. Critical for OpenDrones pre-revenue and for Molt Studios agency clients who don't want map bills.

⌬

3D Vector Tiles

Real buildings extrude from geometry via fill-extrusion paint properties. 3D terrain via raster-dem source. Custom shader hooks for GPU-accelerated effects. WebGL2 backs it all — same GPU path as WebGPU (P2).

⚡

Custom Layers

Custom WebGL layer hook lets you render raw geometry alongside map tiles. Drone flight paths, NFZ polygons, geofences, telemetry heatmaps — all rendered in one draw call.

🧩

React-Native Bindings

First-party react-map-gl (Uber) + maplibre-react wrappers mean the Mission Control stack stays in React. Controlled props, refs, hooks — the same component model OpenDrones already uses.

📡

Composable with P1/P2 Stack

Pairs directly with WebGPU (P2, airspace 3D), Highlight API (P1, fleet search), Subgrid (P1, telemetry tables), @property (P1, animated battery bars). All primitives ship together as one Mission Control page.

🔓

Self-Hostable PMTiles

Protomaps PMTiles format ships the whole planet in a single 100GB static file. Serve it from your CDN for sub-200ms tile loads anywhere on Earth with zero API keys.

03The Anatomy of a Mission Control Airspace Layer

MapLibre models the world as layers — sources feed geometry, layers style and render it. Three primitive types: circle (drone markers), line (flight paths), fill (NFZ polygons). Plus fill-extrusion for real 3D buildings and the custom hook for arbitrary GPU work. 

// 1. Map init — pitch + bearing for the hero 3D angle
const map = new maplibregl.Map({
  container: 'map',
  style: 'https://tiles.openfreemap.org/styles/liberty',
  center: [-122.4194, 37.7749], // SF
  zoom: 14.5,
  pitch: 55,                 // 3D view
  bearing: -17,
  antialias: true,
});

// 2. Source — flight paths as a FeatureCollection (GeoJSON)
map.addSource('flights', {
  type: 'geojson',
  data: {
    type: 'FeatureCollection',
    features: [
      { type: 'Feature', properties: { id: 'AC-7421' },
        geometry: { type: 'LineString',
          coordinates: [[-122.418,37.775], [-122.417,37.776], ...] } }
    ]
  }
});

// 3. Line layer — flight path with dashed style
map.addLayer({
  id: 'flight-paths',
  type: 'line',
  source: 'flights',
  paint: {
    'line-color': ['get', 'color'],
    'line-width': 2.5,
    'line-dasharray': [2, 1.5],
    'line-opacity': 0.7
  }
});

// 4. NFZ polygon — no-fly zone, extruded slightly for visibility
map.addLayer({
  id: 'nfz',
  type: 'fill-extrusion',
  source: { type: 'geojson', data: nfzGeoJSON },
  paint: {
    'fill-extrusion-color': '#ff5577',
    'fill-extrusion-opacity': 0.35,
    'fill-extrusion-height': 120        // meters AGL,
    'fill-extrusion-base': 0
  }
});

// 5. Drone markers — animated circles + click popups
for (const drone of fleet) {
  new maplibregl.Marker({ element: droneMarker(drone) })
    .setLngLat(drone.lngLat)
    .addTo(map);
}

04Four OpenDrones Mission Patterns

How MapLibre turns the OpenDrones product surface — from pilot app to insurance review to enterprise fleet dashboard — into an airborne command center.

🚁

Live Airspace Management

Simultaneous real-time position for 1,000+ drones across a city. Compute-side clustering in MapLibre 5.4 means the renderer only draws drones visible in the viewport — 60fps with fleets of any size.

🚫

NFZ Compliance Overlay

Airports, prisons, stadiums, national parks. MapLibre's fill-extrusion renders no-fly zones as 3D volumes (m AGL) so pilots see exactly where they cannot fly, with altitude-aware conflict detection.

📼

Mission Replay (2D Top-Down)

Pairs with our Gaussian Splatting 3D replay (P3) — view the same mission as both a photoreal 3D flythrough and a clean 2D top-down audit trail. Insurance, regulators, and clients see exactly what happened, where, and at what altitude.

🌐

Fleet-Scale Pilot Operations

Enterprise ops dashboards for survey companies, agriculture, inspection, and public safety. Live drone positions + thermal overlay + wind data + restricted airspace — one map for the entire fleet operation.

05The 5-Line Drop-in

<link href="https://unpkg.com/maplibre-gl@5.4.0/dist/maplibre-gl.css" rel="stylesheet">
<div id="map" style="width:100vw;height:100vh"></div>
<script src="https://unpkg.com/maplibre-gl@5.4.0/dist/maplibre-gl.js"></script>
<script>
  new maplibregl.Map({
    container: 'map',
    style: 'https://tiles.openfreemap.org/styles/liberty',

07OpenDrones Production Pipeline

From a captured drone flight to a live, browser-rendered 3D airspace view — the full data path that turns drone telemetry into a $500-2K-per-replay deliverable.

STEP 01

Capture

Drone records 4K video + LiDAR + IMU + GPS at 30Hz. ~2GB raw per 30s flight. Auto-upload to OpenDrones CDN over 5G/Wi-Fi.

STEP 02

Process

Server-side: derive flight path (GeoJSON), detect NFZ intersections, snap to FAA airspace, generate altitude profile. ~30s server-time per minute of flight.

STEP 03

Tile & Style

GeoJSON downsampled to ~10K vertices per flight. Stored alongside PMTiles. A single addSource() call materializes the flight as a MapLibre line layer.

STEP 04

Live Render

Mission Control page opens. MapLibre streams 3D vector tiles from OpenFreeMap. Flight path + NFZ overlays + drone markers render at 60fps in WebGL2.

STEP 05

Replay & Audit

Pilot, client, regulator, or insurance inspector sees the same photoreal + map-based view. Compliance check is one button click: "Did this flight stay below 400ft AGL in NFZ-7421?"
