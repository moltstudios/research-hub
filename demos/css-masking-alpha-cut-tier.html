CSS Masking — the alpha-cut tier

Soft fades, cut-outs, radar sweeps and editorial wipes — paint-time transparency that never touches layout, hit-testing or the DOM.

Baseline 2024 (mask unprefixed: Ch 120 · SF 15.4 · FF 53) Live-probed Brave 154 + CfT 148 · pixel-verified 2026-10-14

This page is itself the demo — the hero above is three stacked masks (a linear wipe on the stripes, a radial aperture on the glow). Everything below re-probes the engine live in your browser and labels every claim as measured, honest warn, or context.

The tier in one sentence: mask-image multiplies the element's paint by the alpha (or luminance) of an image layer — geometry, hit-testing and accessibility untouched; stacking context and box-shadow: consumed.

02 Surface census — and the census trap

The trap: probing CSS.supports(prop, 'none') returns false for every enumerated-value property, because none is not a legal value of mask-mode or mask-composite — the property exists, the probe lies. Always census with a valid value:

The gap: the standard 9-slice mask-border family is still unshipped on Chromium ≤ 154 (every variant parses false) — the only lane is the old -webkit-mask-box-image, which does parse and holds a computed value. On the modern engine there is zero reason to prefix mask-image anymore — the prefixed name is a full alias.

03 The two-world default split — alpha vs luminance

CSS images (gradients, url() bitmaps) are masked by alpha by default. SVG <mask> element references are masked by luminance by default — Rec. 709 weights applied in plain sRGB space, no linearization (probe-measured: red #f00 → 0.211, blue #00f → 0.072, gray #808080 → 0.502). Pick the mode — same gradient, same panel:

Top panel: CSS gradient linear-gradient(90deg,#fff,#000) — in the alpha world those colors are decorative (only alpha counts, and it is 1 everywhere → fully painted). In the luminance world the same colors fade the element to invisible-right.
SVG world: a solid #808080 rect referenced via mask-image: url(#graymask). Default (luminance): gray = 0.502 → the element dims to half. With mask-type:alpha on the SVG mask element: alpha 1 → fully painted. Same rect, two universes.
/* CSS mask-mode beats SVG mask-type beats the source default (measured precedence) */
.el { mask-image: url(#graymask); mask-mode: alpha; }  /* alpha wins over mask-type */
<mask mask-type="alpha">…</mask>                          /* beats the luminance default */

04 mask-composite — four modes, two grammars, one slot

Multiple mask layers composite top-down. add unions, subtract removes lower layers where the top is opaque, intersect keeps only overlap, exclude is xor. Below: layer 1 = left half opaque, layer 2 = right half opaque — pick the operator:

The two-grammar law (measured): the standard name accepts only add|subtract|intersect|exclude; -webkit-mask-composite accepts only its legacy keywords (source-over, source-in, …, xor, copy) — neither name accepts the other's grammar via CSS.supports. But they share one computed slot: set source-in through the prefixed name and it reads back through the standard name. Alias in storage, split at the parser.

06 The shorthand resets all eight — and the mode-segment

mask: is the full-reset shorthand: image, position, size, repeat, origin, clip, composite and mask-mode (docs summaries routinely omit the mode — the grammar has a masking-mode segment, and the reset law below proves it). Longhand lists cycle like background-* when shorter than the image list:

.card {
  mask: url(frame.png) center / cover no-repeat exclude;   /* composite segment: legal */
  mask: linear-gradient(#000,#000) luminance;               /* mode segment: legal (Chromium 148/154 measured) */
}

07 The stacking-context trap

Any non-none mask makes the element a stacking context (pixel-probe: with the mask on, the green sibling z:1 paints over the blue child z:999 trapped inside; mask off, blue wins). A masked hero owns its z-ladder — children can never escape above the page around it:

08 The shadow-erasure law + mask-clip boxes

The default mask-clip: border-box clips the mask painting area to the border box — and everything the element paints outside that area dies with it. A masked card loses its entire box-shadow on both sides, not just where the gradient is transparent (pixel-probe: both flanks go dark). 09 The animatable-geometry law

mask-position and mask-size interpolate (CSS transitions, @keyframes, WAAPI all work — mid-flight 38.3% measured at 400 ms of a 1 s sweep). mask-image itself is discrete: a gradient-to-gradient flip produces zero running animations — even through a registered @property with syntax:"<image>" (measured: 0 animations). Animate the window, not the picture:

el.animate([{ maskPosition: '0% 50%' }, { maskPosition: '100% 50%' }], { duration: 900, fill: 'forwards' });
// Animation runs (measured). vs:
el.animate([{ maskImage: g1 }, { maskImage: g2 }], …);  // discrete jump — no interpolation lane

10 Repeat, size & the tile grid

Masks tile exactly like background-image: a 70px mask tile with repeat repaints the fade across the box (probe: sample at x=20 ≡ x=90, one full period later), while no-repeat masks everything beyond the first tile out of existence — the cheapest hard-edge "reveal window" in CSS:

11 OpenDrones capstone — radar sweep, scrim, HUD reveal

The radar sweep is one registered custom property driving a conic mask: @property --ang interpolates (unlike <image>, <angle> vars animate), so the sweep rotates at full frame rate with zero per-frame JS. The scrim uses a radial mask to keep telemetry legible over any map; the HUD digits use a luminance ramp so label emphasis rides the mask, not the font weight:

The 10-rule checklist

  1. Census with valid values, never 'none' — enumerated props false-negative (§02).
  2. CSS image masks live in the alpha world; your gradient colors are decorative unless you switch modes (§03).
  3. SVG <mask> refs default to luminance — Rec. 709, sRGB space, no gamma linearization (§03).
  4. Precedence: mask-mode > SVG mask-type > source default (§03).
  5. mask: shorthand resets all eight longhands including mask-mode (§06).
  6. Composite keywords don't cross grammars, but the prefixed name round-trips legacy values through the standard readback (§04).
  7. Masked-away areas still take clicks — use clip-path or pointer-events:none for click-through (§05).
  8. A mask creates a stacking context — plan the z-ladder of any masked hero (§07).
  9. Animate mask-position/mask-size; image flips are discrete even via registered <image> vars — register <angle>/<length> vars to drive conics instead (§09, §11).
  10. Shadows and any out-of-box paint die under the default clip — put them on an unmasked wrapper (§08).
