Implementation Example

// AI generates this from prompt: "Create a weather app with current conditions and forecast"
import { useState, useEffect } from 'react';

interface WeatherData {
  current: {
    temp: number;
    condition: string;
    humidity: number;
  };
  forecast: Array<{
    day: string;
    high: number;
    low: number;
  }>;
}

export default function WeatherApp() {
  const [weather, setWeather] = useState(null);
  const [loading, setLoading] = useState(true);

  useEffect(() => {
    fetchWeather().then(data => {
      setWeather(data);
      setLoading(false);
    });
  }, []);

  if (loading) {
    return (
      <div className="grid grid-cols-3 gap-4">
        {[1, 2, 3].map(i => (
          <div key={i} className="animate-pulse bg-gray-700 h-48 rounded-xl"/>
        ))}
      </div>
    );
  }

  return (
    <div className="grid grid-cols-3 gap-4">
      {/* Current conditions */}
      <div className="bg-gradient-to-br from-blue-500 to-blue-600 p-6 rounded-xl text-white">
        <h2 className="text-2xl font-bold">San Francisco</h2>
        <div className="text-6xl my-4">{weather.current.temp}°</div>
        <p className="text-xl">{weather.current.condition}</p>
        <p className="mt-4 opacity-80">Humidity: {weather.current.humidity}%</p>
      </div>

      {/* Forecast cards */}
      {weather.forecast.map((day, i) => (
        <div key={i} className="bg-gray-800 p-6 rounded-xl">
          <p className="text-gray-400 mb-2">{day.day}</p>
          <p className="text-2xl font-bold text-white">{day.high}°</p>
          <p className="text-gray-400">Low: {day.low}°</p>
        </div>
      ))}
    </div>
  );
}

The AI generates this React code using your design system components. No manual rebuilding needed.

Best Practices

✓

Use Real Component Libraries

Build with MUI, shadcn/ui, Ant Design — not generic HTML/CSS. Ensures brand consistency and reduces adaptation time.

✓

Apply Design System Constraints

Define which components, colors, and spacing standards AI must follow. Prevents brand drift and ensures consistency.

✓

Export as JSX, Not Screenshots

AI generates production-ready code, not static images. Developers can export and integrate directly.

✓

Iterate Conversationally

Refine in place without full regeneration. "Make sidebar narrower, add search" modifies existing layout.
