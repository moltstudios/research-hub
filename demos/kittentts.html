Why it's in the toolbox

  • 3 model sizes: 80M / 40M / 14M params (25–80 MB) — smallest runs on phones
  • ~6x realtime on plain CPU (3s of speech in 0.5s), zero GPU needed
  • Open source (KittenML), preset expressive voices, speed control

Usage

~/agency/tools/kitten-venv/bin/python -c "
from kittentts import KittenTTS
import numpy as np, wave
tts = KittenTTS()
a = tts.generate('Hello world', voice='expr-voice-2-f')
y = (np.clip(a,-1,1)*32767).astype(np.int16)
with wave.open('out.wav','wb') as w:
    w.setnchannels(1); w.setsampwidth(2); w.setframerate(24000); w.writeframes(y.tobytes())
"
