3. Adaptive Dark Mode

Toggle dark mode to see perceptually consistent colors. Dark mode uses higher lightness (L) for accents so they pop against dark backgrounds.

BG

Text
oklch(0.20/0.90 0 0)
Accent
oklch(0.55/0.70 0.25 280)
Surface
oklch(0.96/0.20 0.01/0.02 280)

The accent in dark mode has L=0.70 (brighter) while light mode has L=0.55. Same chroma and hue → same color identity, just adapted.
