CSS Anchor Positioning + Popover API

Position Anything, Zero JavaScript

Tooltips, menus, dropdowns, and hover cards — all positioned natively in CSS. No libraries, no resize observers, no manual calculations. The browser handles it all.

Tooltip on Hover

popover="hint" opens on hover/focus. Anchored with position-area: top. Smooth entry with @starting-style.

This tooltip is positioned entirely with CSS — no JS needed!
Works on any element. Browser handles repositioning automatically.
/* The button is the anchor */
.button { anchor-name: --my-anchor; }

/* The tooltip positions itself */
.tooltip {
  position-anchor: --my-anchor;
  position-area: top;
  justify-self: anchor-center;

  /* Animate open/close */
  transition-behavior: allow-discrete;
  &:popover-open { opacity: 1;
    @starting-style { opacity: 0; }
  }
}

Context Menu with Fallbacks

Click the menu button. If near an edge, it auto-flips using position-try: flip-block, flip-inline.

    •
    /* Auto-flip near edges — the most useful incantation */
    .menu {
      position-anchor: --menu;
      position-area: bottom;
      position-try: flip-block, flip-inline, flip-block flip-inline;
    }

    Why This Changes Everything

    • No JavaScript — commandfor/command attributes handle open/close. Anchor CSS handles positioning.
    • Top-layer stacking — popovers render above everything, no z-index wars.
    • Auto-flip fallbacks — position-try: flip-block, flip-inline handles edge cases.
    • Animated open/close — @starting-style + transition-behavior: allow-discrete animates display:none.
    • Scroll-aware — anchored elements follow their anchor on scroll, automatically.
    • Accessible by default — Esc to close, focus management, screen reader support built in.
    • anchor-size() — size positioned elements relative to their anchor's dimensions.
