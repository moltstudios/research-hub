field-sizing: content — the form-sizing tier

§1The cursor-width floor — an empty field is one caret wide

With field-sizing: content and NO min-width, an empty text input collapses to roughly the width of the text cursor. This inverts 30 years of form defaults — always ship a min-width.

§2The placeholder sets the initial size

A control with a placeholder renders large enough to show the whole placeholder — the placeholder is content for sizing purposes. Type one character and the field re-fits to the typed text (plus the caret), which can SHRINK the field below placeholder width.

§3The size / rows / cols nullification

§4The width→height→scroll ladder (textarea)

A growing textarea first grows INLINE until a width constraint, then grows in BLOCK direction until a height constraint, then shows a scrollbar. Type in the box: width fills to max-width, then lines wrap and height climbs to max-height, then it scrolls. The JS auto-grow pattern (scrollHeight on every keystroke) is now one declaration.

§5The min/max clamp law + maxlength stop

min-width/max-width are the intended companion, not an override: the control shrinks and grows between them. maxlength stops growth at the character limit for free. An explicit width/height, however, RE-IMPOSES a fixed size — the property yields to them entirely.

§6The select re-fit — dropdowns track the selected option

Default: a dropdown is as wide as its LONGEST option, forever. With content sizing it re-fits to the SELECTED option on every change — layout shifts on selection (a design decision, not a bug). Listboxes (multiple) grow to show every option without scrolling.

§11Recipe

/* auto-grow textarea, bounded */
textarea.autogrow {
  field-sizing: content;
  min-height: 2.4em;
  max-height: 9em;      /* then it scrolls */
  overflow: auto;
  resize: none;         /* the control resizes itself now */
}

/* growing input, caret-floor protected */
input.grow {
  field-sizing: content;
  min-width: 8ch;       /* without this: caret-width field */
  max-width: 100%;
}

/* select that fits the selection */
select.fit { field-sizing: content; }

/* progressive enhancement — default IS the fallback */
@supports (field-sizing: content) { /* optional polish */ }
