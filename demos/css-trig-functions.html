1. Circular Orbit (Drone Propellers)

Six elements orbit around a center using CSS sin() and cos() functions. Perfect for animated drone propeller indicators or orbital product showcases. Zero JavaScript required — all positioning and animation handled in CSS.

2. Wave Text Typography

Letters oscillate vertically using sin() with staggered delays. Creates organic, breathing typography perfect for hero sections and brand animations. Each character has a unique offset creating smooth wave motion.

C S S T R I G !
/* Wave each character with sin() */ .wave-char { --offset: 0; transform: translateY( calc(sin(var(--offset) * 30deg) * 20px) ); animation: wave 2s ease-in-out infinite; } /* Stagger offsets for wave effect */ .wave-char:nth-child(1) { --offset: 1; } .wave-char:nth-child(2) { --offset: 2; } .wave-char:nth-child(3) { --offset: 3; }
