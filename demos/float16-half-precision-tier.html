Float16Array — the half-precision tier

Float16Array · Math.f16round · DataView.getFloat16/setFloat16 · ImageData {pixelFormat:'rgba-float16'} · getContext('2d',{colorType:'float16'}). The 2-byte float the whole GPU world already speaks (HDR pixels, ML weights, half-float textures) finally has a first-class JS type — shipped quietly across every engine (Chrome/Edge 135+, Firefox 129+, Safari/iOS 18.2+ → solidly Baseline by now). Zero prior catalog coverage across 216 entries (grep-verified). Every claim below is re-probed live in this page on every visit.

Why it matters: OpenDrones telemetry buffers and GPU texture uploads are the two native habitats of half precision — this tier measures exactly which sensor values survive the 11-bit significand and which are silently destroyed. Molt gets the HDR pixel lane: rgba-float16 ImageData carries values beyond [0,1] that 8-bit pixels physically cannot hold.

§1 — Surface census: the zero-new-vocabulary law live

The entire new surface = the constructor + two DataView methods + one Math static. Everything else is inherited from the hidden %TypedArray% base — measured, not assumed.

§2 — The range grammar: the overflow cliff & the subnormal floor live

Max finite 65504. Everything from 65504 up to 65519.999… rounds DOWN to 65504 — then 65520 and above become Infinity. No exception, no warning: silent destruction.

§3 — The rounding lab: bit inspector interactive

Type any number → its f16 rounding, error, ULP at that magnitude, and the raw 16 bits (sign · exponent · mantissa) via a real DataView write.

The ties-to-even battery: IEEE 754 rounds binary midpoints to the even mantissa — the reason 2049 becomes 2048 (not 2050) and 359.9° becomes 360°.

§4 — The precision grammar: dyadic values & the integer ceiling live

11-bit significand ≈ 3.3 significant decimal digits — but values that are exact binary fractions (.5, .25, .125…) are EXACT at any magnitude in range. Integers stay exact only through 2048.

§5 — Telemetry truth table live — the OpenDrones capstone

Real mission-control values through the f16 gate, measured live. Verdicts: EXACT (dyadic) · FINE (rel err < 0.03%) · LOSSY (visible corruption) · DESTROYED (overflow/Infinity).

§6 — Memory, interop & the Atomics wall live

Half the bytes of f32, full typed-array citizenship — cloneable, transferable — but Atomics enforces the integer-only wall with a verbatim message.

§7 — HDR ImageData: the strict-pairing law live

A Float16Array is ONLY accepted as pixel data when you say {pixelFormat:'rgba-float16'} — the pairing is enforced in BOTH directions, and even colorSpace-only options throw.

§8 — The float16 canvas: colorType, tone mapping & the premultiplied law live

Chrome 135+ grew real {colorType:'float16'} 2d contexts. Pixel values beyond [0,1] survive put→get roundtrips — but alpha-zero pixels lose their RGB to premultiplication.

§9 — WebGL2: the upload rejection & the working lanes live

The surprise: texImage2D(..., HALF_FLOAT, float16Array) is REJECTED on this engine (INVALID_OPERATION 0x502) — the JS-native half type is locked out of the classic GL lane, while Uint16Array bits and the FLOAT-conversion route both pass.

§10 — The precision sawtooth (visual) live

Rounding error of every value in [0,1) — amplified 4096×. The sawtooth amplitude doubles at every binade boundary: the 11-bit significand's signature. There are exactly 15,361 distinct f16 values in [0,1] (vs 251 steps in unorm8, ~10⁹ in f32).

The 10 rules:
  • 1. f16 ≈ 3.3 significant decimal digits; rel err ≤ 2⁻¹¹ (0.049%) anywhere in range.
  • 2. The overflow cliff: ≥65520 → Infinity, silently. Guard magnitude BEFORE storing.
  • 3. Integers are exact only through ±2048; 2049 → 2048 (ties-to-even), 4097 → 4096.
  • 4. Dyadic decimals (.5/.25/.125…) are exact at any magnitude in range — 23.5 °C costs zero error.
  • 5. Never store epoch ms (1.77×10¹² → ∞). Store seconds + separate ms int, or f64.
  • 6. Never store lat/lon: 40.7128 → 40.71875 = 663 m of pure rounding error.
  • 7. new ImageData(f16, w, h) without {pixelFormat:'rgba-float16'} throws — the options dict is mandatory.
  • 8. Default canvases quantize f16 pixels through 8-bit unorm on read (clamp + 255ths); only {colorType:'float16'} contexts preserve HDR — and alpha 0 destroys RGB (premultiplication).
  • 9. WebGL2 HALF_FLOAT upload wants Uint16Array; the Float16Array view itself is rejected (0x502) — convert with Math.f16round into bits, or upload FLOAT + RGBA16F and let the driver convert.
  • 10. Atomics are integer-only by verbatim law — shared f16 buffers coordinate via f32/int views over the same SAB.
