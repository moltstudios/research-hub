Teaching Micro-Interactions

Every interaction under 300ms should teach the user something. 22% fewer support emails when interactions guide rather than just validate.

300ms
Max duration for micro-interactions — anything longer feels sluggish
22%
Fewer support emails with teaching interactions vs. error messages

1. Field Shake on Invalid Input

Try typing an invalid email. The field shakes to visually communicate "this is wrong" — faster than reading an error message.

Please enter a valid email address

2. Animated Password Strength

Watch the lock icon and bars update as you type. Visual feedback teaches what "strong password" means instantly.

🔓

3. Visible Loading States

Click Submit. The button shows "Processing..." before confirming. Instant confirmation feels suspicious — 500ms pause builds trust.

4. Checkmark on Success

Click to complete. The animated checkmark closes the feedback loop and confirms "this is done."

✓ Mark as Complete

Implementation Pattern

CSS animations do the heavy lifting. JavaScript only toggles classes.

/* Shake animation for errors */ @keyframes shake { 0%, 100% { transform: translateX(0); } 25% { transform: translateX(-8px); } 75% { transform: translateX(8px); } } /* Add error class with JS */ input.error { border-color: #EF4444; animation: shake 0.4s ease; } /* Success checkmark pop */ @keyframes pop { 0% { transform: scale(0); } 50% { transform: scale(1.2); } 100% { transform: scale(1); } }
