The Syntax

Three values: minimum size, preferred scaling, maximum size.

font-size: clamp(1rem, 2vw + 0.5rem, 2.25rem); /* */ /* Minimum: 1rem (16px) — can't go smaller */ /* Preferred: 2vw + 0.5rem — scales with viewport */ /* Maximum: 2.25rem (36px) — can't go larger */ /* */ /* Fluid headline: 28px → 64px */ .hero-text { font-size: clamp(1.75rem, 4vw, 3rem); }
❌ Old Way: Breakpoints
h1 { font-size: 2rem; }
@media (min-width: 768px) { h1 { font-size: 2.5rem; } }
@media (min-width: 1024px) { h1 { font-size: 3rem; } }

Jumps at 768px and 1024px

✓ New Way: Fluid
h1 { font-size: clamp(1.75rem, 4vw, 3rem); }

Smooth scaling at every pixel

Complete Fluid Scale

A full typographic scale using clamp() for every element type.

/* Headlines scale dramatically */ .h1 { font-size: clamp(1.75rem, 4vw, 3rem); } .h2 { font-size: clamp(1.25rem, 2.5vw, 1.75rem); } .h3 { font-size: clamp(1rem, 1.8vw, 1.25rem); } /* Body stays mostly steady */ .body { font-size: clamp(0.875rem, 1.2vw, 1rem); } .caption { font-size: clamp(0.75rem, 1vw, 0.875rem); } /* Metrics get large on desktop */ .metric { font-size: clamp(2rem, 6vw, 5rem); }

Best Practices

✓ Do use for:

  • • Headlines and display text — scales dramatically on mobile
  • • Section headers — needs to grow on desktop
  • • Metrics and stats — should get much larger on big screens

✗ Avoid for:

  • • Body text — keep steady (min close to max)
  • • UI labels — need consistent tap targets
  • • Code or fixed-width content
