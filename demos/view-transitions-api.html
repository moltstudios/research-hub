View Transitions API

Native browser transitions for smooth page-to-page animations

What is it?

The View Transitions API is a browser-native mechanism for animating between two DOM states. When triggered, the browser takes a snapshot of the current page, applies your DOM changes, then crossfades or otherwise animates between the old and new snapshots using CSS.

Key benefit: No JavaScript animation libraries needed. Transitions run on the compositor thread for 60fps performance even during heavy JavaScript execution.

Implementation Code

Enable in CSS (Single Line!)

@view-transition { navigation: auto; /* Enables native cross-document transitions */ }

Custom Animation (CSS Pseudo-elements)

::view-transition-old(root) { animation: fade-out 400ms ease-out; } ::view-transition-new(root) { animation: fade-in 400ms ease-in; } @keyframes fade-out { from { opacity: 1; } to { opacity: 0; } } @keyframes fade-in { from { opacity: 0; } to { opacity: 1; } }

Next.js 16 / React 19.2 Setup

// next.config.ts const nextConfig = { experimental: { viewTransition: true, }, } // layout.tsx import { unstable_ViewTransition as ViewTransition } from 'next' export default function RootLayout({ children }) { return ( <html> <body> <ViewTransition>{children}</ViewTransition> </body> </html> ) }

Key Features & Benefits

Zero JavaScript Animations

All animation logic lives in CSS keyframes. No JavaScript animation loop required.

Compositor Thread Performance

Transitions run on the GPU at 60fps even during heavy JavaScript execution.

Shared Element Morphing

Automatically animates elements between positions and sizes across route changes.

~3KB Bundle Size

Replaces heavy animation libraries like Framer Motion (~40KB) or GSAP.

Works with React Suspense

Natively composes with Suspense boundaries for loading state animations.

Progressive Enhancement

Graceful fallback in unsupported browsers — navigation works, just no animation.

Browser Support

// Same-document transitions (startViewTransition) ✅ Chrome, Edge, Safari 18+ // Cross-document transitions (@view-transition) ✅ Chrome 126+, Edge 126+ ⚠️ Safari & Firefox: Not yet supported // React <ViewTransition> component ✅ React 19.2+, Next.js 16+

Note: For unsupported browsers, navigation works normally — users just won't see transition animations. This is progressive enhancement.

Common Animation Patterns

Slide Transition (Left to Right)

::view-transition-old(root) { animation: slide-out-left 250ms ease; } ::view-transition-new(root) { animation: slide-in-right 250ms ease; }

Fade + Scale (Depth Effect)

::view-transition-old(root) { animation: fade-out 200ms ease; } ::view-transition-new(root) { animation: scale-in 300ms ease; }

Accessibility: Respect Reduced Motion

@media (prefers-reduced-motion: reduce) { ::view-transition-group(*) { animation-duration: 0.001ms; } }
