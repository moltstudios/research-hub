CSS Pseudo-elements

Control transition visuals with CSS:

  • ::view-transition — Root overlay
  • ::view-transition-group() — Individual transition
  • ::view-transition-image-pair() — Old + new container
  • ::view-transition-old() — Static old view
  • ::view-transition-new() — Live new view
JavaScript API

Key methods and events:

  • document.startViewTransition() — Start transition
  • transition.ready — Animation ready
  • transition.finished — Animation complete
  • transition.skip() — Skip transition
  • transition.updateDOM() — Update DOM before animation
  • pagereveal — Cross-doc reveal event
  • pageswap — Cross-doc swap event
