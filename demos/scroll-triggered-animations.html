Zero dependencies. Simple reveal animations using CSS transitions. Perfect for basic viewport detection.

GSAP ScrollTrigger

Powerful scroll-driven animations. Scrubbing, pinning, horizontal scroll, and more.

🎬 Scrubbing

Link animation progress to scroll position. Perfect for parallax and scroll stories.

📌 Pinning

Freeze elements in place while scrolling. Great for hero sections and sticky headers.

🔄 Horizontal Scroll

Drive horizontal content movement with vertical scrolling.

📊 Progress Tracking

Get scroll progress (0-1) for custom counters and scroll depth indicators.

⚡ Performance Optimized

GPU-accelerated with automatic optimization and batch triggers.
