📡 React Signals Pattern

Signals provide fine-grained reactivity without full re-renders — perfect for adaptive UI state that changes frequently.

// React Signals — fine-grained reactivity (RFC, React 2026)
import { signal, computed, effect } from 'react-signals';

// Define adaptive state as signals
const userPreferences = signal({
  layout: 'default',
  cardOrder: ['revenue', 'users', 'orders', 'conversion'],
  emphasis: null
});

const interactionCount = signal(0);

// Computed: derive layout from preferences + interactions
const adaptiveLayout = computed(() => {
  const prefs = userPreferences.value;
  const count = interactionCount.value;

  if (count > 10 && prefs.emphasis) {
    return {
      ...prefs,
      layout: 'personalized',
      primaryCard: prefs.emphasis
    };
  }
  return prefs;
});

// Side-effect: persist when layout changes
effect(() => {
  localStorage.setItem(
    'adaptive-layout',
    JSON.stringify(adaptiveLayout.value)
  );
});

🔄 useSyncExternalStore for Adaptation

Bridge external adaptation engines into React's rendering lifecycle without tearing or flickering.

import { useSyncExternalStore } from 'react';

// Adaptation store — external to React
const adaptationStore = {
  listeners: new Set(),
  state: { layout: 'default', priority: [] },

  subscribe(listener) {
    this.listeners.add(listener);
    return () => this.listeners.delete(listener);
  },

  getSnapshot() {
    return this.state;
  },

  adapt(userBehavior) {
    // Run adaptation logic (could be ML model output)
    this.state = computeAdaptation(userBehavior);
    this.listeners.forEach(l => l());
  }
};

// React hook
function useAdaptiveUI() {
  return useSyncExternalStore(
    adaptationStore.subscribe.bind(adaptationStore),
    adaptationStore.getSnapshot.bind(adaptationStore)
  );
}

⚡ Edge AI Pattern

Run lightweight adaptation models directly in the browser for zero-latency personalization.

// Edge AI adaptation — runs in-browser with ONNX Runtime Web
import { InferenceSession } from 'onnxruntime-web';

const session = await InferenceSession.create('./adaptation-model.onnx');

async function predictLayout(interactionHistory) {

  const { output } = await session.run({ input });

  // Output: layout config probabilities
  const layoutIndex = output.data.indexOf(

// Debounce: only re-predict every 2 seconds of inactivity
const debouncedPredict = debounce(predictLayout, 2000);

// Wire to interaction tracker

🧩 Core Concepts

Real-Time Adaptation

UI reconfigures based on live user signals — click patterns, scroll depth, dwell time — without page reloads or explicit settings.

Context-Aware Rendering

Components receive environmental context (time of day, device, location, usage history) and render differently for each situation.

Predictive UI

Machine learning models predict what the user will need next and pre-render/pre-fetch accordingly, reducing perceived latency.

Progressive Personalization

Start with sensible defaults. Adapt incrementally as confidence grows. Never show a "personalizing..." state — make changes invisible.

Privacy-First Adaptation

All adaptation runs client-side by default. User behavior data stays in the browser. Server-side models only receive anonymized, aggregated signals.

Graceful Degradation

If the adaptation engine fails or takes too long, the UI falls back to the default layout instantly. No broken states.
