CSS @scope Rule Baseline 2026

What is @scope?

The @scope CSS at-rule enables you to select elements in specific DOM subtrees, targeting elements precisely without writing overly-specific selectors that are hard to override, and without coupling your selectors too tightly to the DOM structure. It's now Baseline 2026 compatible — supported in all major browsers (Chrome 111+, Firefox 146+, Safari 18.2+).

Key Benefit: Eliminates the need for complex naming conventions like BEM, reduces style leaks, and prevents the specificity wars that plague large CSS codebases.

Demo 1: Basic @scope Usage

Scope styles to a specific container without affecting the rest of the page. Styles inside @scope only apply to elements within the scoping root.

@scope (.basic-scope-container) { h4 { color: #667eea; } p { font-weight: 500; } button { background: #667eea; } }

Demo 2: Donut Scope 🍩

Use the to keyword to create a "donut scope" — styles apply within the root but exclude elements matching the lower bound. This is perfect for component slots where you don't want outer styles leaking in.

@scope (.donut-scope-container) to (.excluded-slot) { h4 { color: #e74c3c; } p { background: #ffeaa7; font-weight: 600; } } /* Elements inside .excluded-slot are NOT affected */

Demo 3: Multiple Slots

Create multiple "holes" in your scope using a comma-separated list. Styles apply everywhere except the specified slots.

@scope (.multi-slot-container) to (.slot-a, .slot-b, .slot-c) { p { background: #98fb98; color: #1e7e34; } }

Demo 4: Scope Proximity ⚡

When two scopes have conflicting styles with equal specificity, the closer scope wins. This is a game-changer for nested components!

Demo 5: Nested @scope Blocks

You can nest @scope blocks inside each other for deeply nested component styling. Each level maintains its own isolation.

@scope (.nested-outer) { @scope (.nested-middle) { @scope (.nested-inner) { /* Three levels deep */ } } }

Demo 6: :scope Pseudo-Class

The :scope pseudo-class inside @scope refers back to the scope root itself. Use it to style the root or create precise relationship requirements.

@scope (.scope-root-demo) { :scope { /* Styles the root element itself */ background: linear-gradient(135deg, #f5f7fa 0%, #c3cfe2 100%); padding: 1.5rem; border-radius: 8px; } h4 { color: #667eea; } }

Demo 7: Real-World Card Component

@scope shines for component styling. Here's a reusable card where styles apply to header/body/footer but exclude the content slot (where user content goes).

@scope (.card-component) to (.card-content-slot) { :scope { background: white; border-radius: 12px; box-shadow: 0 4px 15px rgba(0,0,0,0.1); } .card-header { background: linear-gradient(...); } .card-body { padding: 1.5rem; } .card-footer { background: #f8f9fa; } } /* User content inside .card-content-slot is NOT affected */
