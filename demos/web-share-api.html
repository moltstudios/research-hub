Web Share API

Native browser sharing — invoke the OS share sheet with text, URLs, and files using a single JavaScript call.

📤 What Is the Web Share API?

The Web Share API lets web apps invoke the native operating system sharing dialog — the same sheet that appears when you tap "Share" in a native app. No custom share menus, no third-party SDKs.

Two methods: navigator.share() to send data out, and navigator.canShare() to check if a payload is valid before attempting.

JavaScript // Feature detection — always check first if (navigator.share) { await navigator.share({ title: 'My Page', text: 'Check this out!', url: 'https://example.com', }) } else { // Fallback: copy to clipboard, custom share UI, etc. showFallbackShareMenu() }

💻 Code Examples

1. Basic Share (Text + URL)

JavaScript async function shareLink() { if (!navigator.share) { showToast('Sharing not supported') return } try { await navigator.share({ title: 'Molt Studios', text: 'Check out this amazing agency!', url: 'https://moltstudios.com', }) console.log('Share successful') } catch (err) { if (err.name !== 'AbortError') { console.error('Share failed:', err) } // User cancelled — not an error } }

2. File Sharing

JavaScript async function shareFile() { // Create a file to share const file = new File( ['Hello from the Web Share API!'], 'hello.txt', { type: 'text/plain' } ) // Check if files are supported if (navigator.canShare && navigator.canShare({ files: [file] })) { await navigator.share({ files: [file], title: 'Shared Document', text: 'Here is a file for you', }) } else { showToast('File sharing not supported') } }

3. Share Target (PWA)

JSON — manifest.json { "name": "My App", "share_target": { "action": "/share-receive", "method": "POST", "enctype": "multipart/form-data", "params": { "title": "title", "text": "text", "url": "url", "files": [{ "name": "media", "accept": ["image/*"] }] } } }

4. Feature Detection + Fallback

JavaScript function shareOrFallback(data) { if (!navigator.share) { // Fallback: copy URL to clipboard return navigator.clipboard.writeText(data.url) .then(() => showToast('Link copied!')) } // Validate payload with canShare if available if (navigator.canShare && !navigator.canShare(data)) { showToast('This share payload is not supported') return } return navigator.share(data) } // React component example function ShareButton() { const supported = 'share' in navigator return ( <button onClick={() => shareOrFallback(payload)}> {supported ? 'Share' : 'Copy Link'} </button> ) }

⚠️ Gotchas & Best Practices

  • 🔒 Requires HTTPS (or localhost). Won't work on HTTP.
  • 👆 Requires user gesture. Can't call navigator.share() automatically — must be triggered by a click/tap.
  • ❌ AbortError is normal. When the user dismisses the share sheet, it throws AbortError. Don't treat it as a failure.
  • 📋 Always provide a fallback. Desktop Firefox and older browsers don't support it. Copy-to-clipboard is the standard fallback.
  • 🧪 Use canShare() to validate. Before sharing files, check navigator.canShare({files: [...]}) to avoid runtime errors.
  • 📄 File type restrictions. Some platforms limit which file types can be shared. Use standard MIME types.
  • 📱 Mobile-first API. Desktop support is relatively new (Chrome 128, 2024). Expect primarily mobile usage.
