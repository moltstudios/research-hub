CSS Subgrid

The missing piece of CSS Grid. Nested grids that inherit the parent grid's track sizing — so cards align by title, forms align by label, pricing tables align by column, and dashboards stay readable at any width. Zero JavaScript.

CSS Grid Level 2 Chrome 117+ Safari 16+ Firefox 71+ Edge 117+ Baseline Widely Available ~89.8% global

1 The nested-grid alignment problem

For 6+ years after CSS Grid shipped (2017), nested grids were independent of the parent. Each card was its own grid with its own track sizes, so titles, prices, and CTAs in a row of cards never lined up. You needed JS, fixed pixel heights, or flexbox hacks to fake alignment.

/* The fix — one CSS line per axis */
.card {
  display: grid;
  grid-template-rows: subgrid;     /* inherit parent's row tracks */
  grid-row: span 4;            /* title, body, price, cta */
  row-gap: 0.5rem;
}

/* And the parent grid defines the row tracks: */
.card-grid {
  display: grid;
  grid-template-columns: repeat(auto-fit, minmax(220px, 1fr));
  grid-auto-rows: auto auto auto auto;  /* 4 tracks: title/body/price/cta */
}

2 Aligned form labels and inputs

A 30-year CSS pain point: making label + input pairs align vertically across a form. Flexbox + `width: 30%` on labels works but breaks on narrow screens. Subgrid gives you a true 2-column form where the labels can be as wide as the longest label, and inputs fill the rest — without JS.

.form-grid {
  display: grid;
  grid-template-columns: [labels] auto [inputs] 1fr;
  gap: 0.75rem 1.25rem;
}

.field-row {           /* every label+input pair */
  display: grid;
  grid-template-columns: subgrid;
  grid-column: 1 / -1;      /* span the whole parent */
}
✅ Resize the window — at <720px the layout collapses to single column. The subgrid automatically inherits the new parent tracks (just one column). Labels and inputs stack cleanly.

3 Pricing comparison table — no <table> needed

Build a true alignment table using grid + subgrid instead of HTML <table>. Cells line up perfectly across rows and across grouped sections. Way more flexible than colspan/rowspan.

.pricing-grid {
  display: grid;
  grid-template-columns:
    [feat] minmax(180px, 1.5fr)
    repeat(3, [plan] minmax(120px, 1fr));
}

.feat-group {           /* a section header + its features */
  display: grid;
  grid-template-columns: subgrid;
  grid-column: 1 / -1;
}

4 OpenDrones Mission Control — telemetry table

A real-world pattern for our drone fleet dashboard. Headers and rows both use the same grid template. Rows inherit the parent's column tracks via subgrid, so every drone ID, name, status, battery, altitude, signal, and action lines up perfectly — even with dynamic content of variable width.

.telemetry-grid {
  display: grid;
  grid-template-columns:
    [id] 70px [name] minmax(140px, 1.5fr)
    [status] minmax(110px, 1fr) [battery] minmax(110px, 1fr)
    [alt] minmax(90px, 1fr) [signal] minmax(110px, 1fr)
    [action] minmax(80px, auto);
}

.telemetry-grid .row {
  display: grid;
  grid-template-columns: subgrid;
  grid-column: 1 / -1;     /* span every column */
  align-items: center;
}

5 Definition-list-style stat blocks

A common dashboard pattern: a label on the left, value on the right. Subgrid keeps the label width dynamic (longest label wins) and the value column right-aligned, without any magic numbers.

.stat-list {
  display: grid;
  grid-template-columns: [label] 1fr [value] auto;
}

.stat-list .stat {
  display: grid;
  grid-template-columns: subgrid;
  grid-column: 1 / -1;
}

6 Named grid lines pass to subgrid

If the parent grid has named lines (like [wide-start] ... [wide-end]), a subgrid can reference those names to position its own items against the parent's logical regions. Useful for magazine-style layouts, article bodies with sidebars, and complex responsive grids.

.named-grid {
  display: grid;
  grid-template-columns:
    [wide-start] 1fr [content-start] 2fr [content-end] 1fr [wide-end];
}

.nested-subgrid {
  display: grid;
  grid-template-columns: subgrid;     /* inherits wide-start / wide-end */
  grid-column: wide-start / wide-end;
}

7 Why subgrid is a layout revolution

Until subgrid shipped, every nested grid was a separate layout universe. Subgrid closes that 6-year gap and unlocks a tier of layouts that previously needed JS, tables, or rigid pixel measurements.

Use caseBefore subgridWith subgrid
Card grid with aligned titles/CTAs JS measures tallest card, sets min-height on all grid-template-rows: subgrid + grid-row: span N
Form with aligned labels Set label width: 30% + media queries for narrow screens Subgrid inherits dynamic label width from longest label
Pricing comparison table HTML <table> (semantic mismatch) or hard-coded grid for every breakpoint One grid + subgrid + named lines, all responsive
Dashboard data tables Fixed grid-template-columns: repeat(7, 1fr) in every row Define columns once on parent, rows inherit via subgrid
Magazine / article layouts Absolute positioning, magic numbers, JS for sidebar height Named grid lines pass through subgrid hierarchies
