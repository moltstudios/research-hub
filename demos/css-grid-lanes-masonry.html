02

The 3-Line Recipe

That's it. Zero JavaScript. Zero media queries.

💡
The entire API in 3 lines of CSS: Set display: grid-lanes, define tracks with grid-template-columns (or grid-template-rows), and set a gap. The browser handles the masonry packing algorithm natively. 
.container {
  display: grid-lanes;
  grid-template-columns: repeat(auto-fill, minmax(250px, 1fr));
  gap: 16px;
}

Compare this to the old approach: importing masonry.js (8KB), calling new Masonry('.grid', {...}), handling resize observers, re-layout on image load, and filtering mutations. All gone.

04

Variable-Width Lanes

Full power of Grid track sizing — alternating narrow and wide columns.

🎨
Because Grid Lanes uses grid-template-*, you can create patterns impossible with the classic Masonry.js approach — like alternating 1fr 2fr 1fr 2fr tracks. 
/* Alternating narrow + wide lanes */
.pattern {
  display: grid-lanes;
  grid-template-columns:
    repeat(auto-fill, minmax(8rem, 1fr) minmax(16rem, 2fr))
    minmax(8rem, 1fr);
  gap: 1rem;
}

/* Content fills the pattern naturally */
/* No JS, no resize observer, no re-layout */

Spanning & Explicit Placement

Items can span multiple lanes, just like CSS Grid.

📍 Spanning Lanes
article { grid-column: span 1; }

/* Featured article spans 4 columns on wide screens */
@media (1250px < width) {
  article:nth-child(1) {
    grid-column: span 4;
  }
  article:nth-child(2),
  article:nth-child(3) {
    grid-column: span 2;
  }
}
🎯 Explicit Placement
/* Header always in the last 2 columns */
header {
  grid-column: -3 / -1;
}

/* "Featured" badge in column 2 */
.featured {
  grid-column: 2;
}

Definite placement happens before the masonry packing algorithm runs. Auto-placed items flow around positioned items. This is the same model as CSS Grid — if you know Grid, you know Grid Lanes.

06

Flow Tolerance — The Smart Packing Dial

Control how aggressively the algorithm reorders items to fill gaps.

🚗
Think of it like highway traffic. flow-tolerance: 0 = every car cuts to whichever lane gets them 1 inch ahead. flow-tolerance: 5em = drivers only change lanes for meaningful gaps. Default is 1em. 
/* Default — 1em tolerance */
.container {
  display: grid-lanes;
  grid-template-columns: repeat(3, 1fr);
  flow-tolerance: 1em; /* default */
}

/* High tolerance — items stay in DOM order, only big gaps cause lane changes */
.stable-layout {
  flow-tolerance: 4em;
}

/* Zero tolerance — maximum packing density, items shuffle freely */
.tight-pack {
  flow-tolerance: 0;
}
⚖️ Trade-offs
  • Low tolerance (0-0.5em): Maximum packing density. Items may visually reorder significantly from DOM order. Good for image galleries.
  • Default (1em): Balanced. Small size differences ignored, meaningful gaps filled. Good for most use cases.
  • High tolerance (3em+): Items stay close to DOM order. Better for accessibility / tab order. Good for dashboards where sequence matters.

OpenDrones Mission Control — Dashboard Cards

Telemetry cards of varying heights pack naturally without empty gaps.

🚁
Why Grid Lanes matters for Mission Control: Drone telemetry cards have inherently different heights — a critical alert card has 5 lines, a battery card has 2. With Grid Lanes, cards pack without the empty gaps that display: grid leaves. No JavaScript reflow needed when cards are added/removed. 
.mission-dashboard {
  display: grid-lanes;
  grid-template-columns: repeat(auto-fill, minmax(200px, 1fr));
  gap: 12px;
  flow-tolerance: 2em; /* stable for tab order */
}

/* Featured mission spans 2 columns */
.mission-card.active {
  grid-column: span 2;
}

Fallback Strategy — Ship Today with @supports

Progressive enhancement: native Grid Lanes where available, graceful fallback everywhere else.

/* 1. Base: CSS multi-column fallback (universal) */
.gallery {
  column-count: 3;
  column-gap: 16px;
}
.gallery figure {
  break-inside: avoid;
  margin-bottom: 16px;
}

/* 2. Enhanced: native Grid Lanes (Safari 26.4+) */
@supports (display: grid-lanes)) {
  .gallery {
    display: grid-lanes;
    grid-template-columns: repeat(auto-fill, minmax(250px, 1fr));
    gap: 16px;
    column-count: auto; /* reset */
  }
  .gallery figure {
    margin-bottom: 0; /* gap handles it */
  }
}
⚠️
CSS columns fallback caveat: column-count flows top-to-bottom then next column (newspaper order), while Grid Lanes flows left-to-right (reading order). For accessibility, the columns fallback is slightly different in tab order. Use @supports to enhance — don't block on it.

API Reference — All Properties

The complete Grid Lanes toolkit.

PropertyValuesDefaultNotes
display grid-lanes — Activates masonry layout mode
grid-template-columns Standard Grid track values none Defines vertical lanes (waterfall)
grid-template-rows Standard Grid track values none Defines horizontal lanes (brick)
gap / column-gap / row-gap <length> 0 Spacing between items and between lanes
