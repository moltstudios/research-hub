📂 What Are Parallel Routes?

Parallel Routes let you render multiple pages in the same layout simultaneously. Defined with @slot folders in the App Router, each slot is an independent route that renders its own page component.

Think of it like named outlets in Angular or multiple outlets in Ember — but powered by the URL. Each slot can have its own loading state, error boundary, and suspense boundary.

File Structure

dashboard/
@analytics/ ← parallel slot
page.tsx
@team/ ← parallel slot
page.tsx
layout.tsx ← receives analytics + team props
page.tsx ← default dashboard page
(.)login/ ← intercepting route
page.tsx ← renders as modal

Layout Receives Slots as Props

TypeScript // app/dashboard/layout.tsx export default function DashboardLayout({ children, analytics, team, }: { children: React.ReactNode analytics: React.ReactNode team: React.ReactNode }) { return ( <div className="dashboard-grid"> <main>{children}</main> <aside>{analytics}</aside> <aside>{team}</aside> </div> ) }

🔀 What Are Intercepting Routes?

Intercepting Routes let you load a route from another part of your app within the current layout — perfect for modals. The URL updates, but instead of a full page transition, the content appears in an overlay.

When a user navigates directly to that URL (fresh page load or refresh), the intercepted route renders normally as a full page.

Convention Syntax

Folder Naming (.) → intercept same level (..) → intercept one level up (..)(..) → intercept two levels up (...) → intercept from root app/ // Example: app/dashboard/(.)login/page.tsx // When navigating to /login FROM /dashboard → shows modal // When visiting /login directly → shows full login page

Modal Page Component

TypeScript // app/dashboard/(.)login/page.tsx import { useRouter } from 'next/navigation' export default function LoginModal() { const router = useRouter() function onClose() { router.back() // Dismiss modal via back navigation } return ( <div className="modal-overlay" onClick={onClose}> <div className="modal" onClick={(e) => e.stopPropagation()}> <h2>Log In</h2> <LoginForm /> </div> </div> ) }

🎯 Use Cases

🪟

URL-Powered Modals

Shareable, bookmarkable modals. The URL reflects the modal state, so refreshing keeps it open. Back button dismisses naturally.

📊

Split-View Dashboards

Render dashboard + analytics + team panels independently. Each slot loads its own data with its own loading skeleton.

⏳

Independent Loading States

Each @slot has its own loading.tsx. Slow analytics won't block the main panel from rendering.

📸

Photo/Item Galleries

Click an item → modal overlay. The URL updates for sharing. Direct visit shows the full detail page.

💬

Chat + Content Side-by-Side

Parallel slots for conversation list + active chat. Each navigates independently within the same layout.

🔄

Conditional Rendering

Use default.tsx in @slots to handle cases where no matching route exists. Great for optional panels.

⚡ Key Patterns

default.tsx for Unmatched Slots

TypeScript // app/dashboard/@analytics/default.tsx // Rendered when no matching @analytics route exists export default function DefaultAnalytics() { return <div className="empty-state">Select a view</div> }

Unmatched Parallel Route Handling

TypeScript // Use `null` check — Next.js passes null for unmatched slots export default function Layout({ team, }: { team: React.ReactNode }) { return ( <> {team ?? <div>No team selected</div>} </> ) }
