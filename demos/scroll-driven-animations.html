Zero JavaScript

CSS Scroll-Driven Animations

Scroll-triggered reveals, parallax, and transitions — entirely in CSS. Runs on the compositor thread for buttery smooth performance.

1. Fade Up

Elements slide up from below and fade in as they enter the viewport. The most versatile scroll reveal pattern.

@keyframes reveal-up { from { opacity: 0; transform: translateY(40px); } to { opacity: 1; transform: translateY(0); } } .reveal-up { animation: reveal-up linear both; animation-timeline: view(); animation-range: entry 0% entry 100%; }
↑ Fading Up ↑

2. Slide from Left

Content enters from the left side. Perfect for alternating layouts in service sections.

@keyframes reveal-left { from { opacity: 0; transform: translateX(-60px); } to { opacity: 1; transform: translateX(0); } }
← Sliding In ←

3. Slide from Right

Content enters from the right. Combine with left slides for alternating gallery layouts.

→ Sliding In →

4. Scale Up

Elements grow from 85% to full size. Great for images, cards, and featured content blocks.

@keyframes reveal-scale { from { opacity: 0; transform: scale(0.85); } to { opacity: 1; transform: scale(1); } }
🔍 Scaling Up 🔍

5. Blur In

Content deblurs as it enters the viewport. Creates a cinematic reveal effect — perfect for hero sections.
