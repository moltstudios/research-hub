INP Optimization

scheduler.yield() Demo

This demo shows the difference between blocking and non-blocking interactions. Click the filter chips below. Notice how instant the feedback is when tasks are yielded. Impact: INP drops 60-65% at 75th percentile.

Code Pattern:

async function handleFilterTap(filter) { setSelectedFilter(filter); // Paint immediately await yieldToMain(); // Yield to browser const filtered = applyFilters(products, filter); await yieldToMain(); setResults(filtered); } function yieldToMain() { if ("scheduler" in window && "yield" in window.scheduler) { return window.scheduler.yield(); } return new Promise(resolve => setTimeout(resolve, 0)); }

2026 Optimization Checklist

  • Default to React Server Components (zero JS to browser)
  • Only add "use client" for event handlers, browser APIs, useState, useEffect
  • Set revalidate or cache tags on all data fetches (eliminates 80% of DB calls)
  • Add priority prop to above-fold images
  • Use sizes prop on all responsive images
  • Dynamic-import heavy components and libraries (reduces initial bundle 30-50%)
  • Use scheduler.yield() for expensive event handlers
  • Use useDeferredValue for heavy render paths
  • Offload third-party scripts to web workers
  • Run @next/bundle-analyzer before every major release
  • Deploy to Vercel Edge for global distribution
  • Monitor CrUX data (not just Lighthouse)
