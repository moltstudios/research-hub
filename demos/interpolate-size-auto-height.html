CSS interpolate-size & calc-size()

Animate to and from height: auto, max-content, fit-content — no JavaScript, no hacks, no layout thrashing.

/* Enable for entire document — one line */
:root {
  interpolate-size: allow-keywords;
}

/* Now transitions to/from auto just work */
.accordion-body {
  height: 0;
  overflow: clip;
  transition: height 0.5s ease;
}

.accordion-body.open {
  height: auto; /* ✨ Smoothly animates! */
}

1 Smooth Accordion (height: 0 → auto)

No max-height hacks, no JS measurement. Pure CSS with interpolate-size: allow-keywords on :root.

The CSS interpolate-size property controls whether intrinsic sizing keywords (like auto, max-content, fit-content) can be smoothly animated. Setting it to allow-keywords on :root enables smooth height/width transitions to/from these values for the entire document. It's inherited, so one declaration covers everything.
The max-height hack creates two problems: (1) The animation timing is wrong — if content is 100px but max-height transitions from 9999px, the first 9899px of the animation is invisible, making the visible portion of the animation much faster than intended. (2) You need to guess a large-enough max-height, which can cause issues with varying content. With interpolate-size, the browser knows the actual content height and animates at the correct speed.
calc-size() is the advanced companion. While interpolate-size simply enables auto ↔ fixed transitions, calc-size() lets you do math on intrinsic sizes: calc-size(auto, size - 10px) or calc-size(fit-content, size + 2rem). Use interpolate-size for simple open/close, use calc-size() when you need precise calculations on intrinsic sizes.
interpolate-size and calc-size() are supported in Chrome 129+ (Sep 2024), Edge 129+, Safari 18.4+, and Firefox 146+. That covers ~92%+ of global traffic in 2026. Graceful degradation: unsupported browsers will still open/close, just without the smooth animation — progressive enhancement at its best.

⚡
Performance
Runs on the compositor thread. No JavaScript layout thrashing, no forced reflows measuring scrollHeight. Pure CSS transitions at 60fps even during heavy JS execution.
🎯
Accurate Timing
Unlike max-height: 9999px hacks where the easing curve is wrong, interpolate-size animates at the real content height. Your 0.5s ease actually takes 0.5s of visible animation.
📐
Dynamic Content
Content can change length (different languages, dynamic data, user-generated content) and the animation still works perfectly because the browser resolves auto at transition time.
♿
Accessible
Works naturally with semantic HTML like <details>/<summary>. Combine with @starting-style for entry animations. Respects prefers-reduced-motion when you wrap in a media query.

7 Key Implementation Patterns

/* Pattern 1: Global opt-in (recommended) */
:root { interpolate-size: allow-keywords; }

/* Pattern 2: Scoped opt-in */
main { interpolate-size: allow-keywords; }

/* Pattern 3: Accordion / Disclosure */
details {
  height: 2.5rem;
  overflow: clip;
  transition: height 0.5s ease;
}
details[open] { height: auto; }

/* Pattern 4: calc-size() for math */
.tooltip {
  width: calc-size(fit-content, size + 1rem);
}

/* Pattern 5: Entry animation with @starting-style */
.toast {
  height: auto;
  opacity: 1;
  transition: height 0.4s ease, opacity 0.3s ease;
  @starting-style {
    height: 0;
    opacity: 0;
  }
}
