Cross-document How this works

Each product card sets view-transition-name on its preview thumbnail. When you navigate to the detail page, the browser snapshots both the old and new DOM states, finds elements with matching names, and morphs them — even across a full page reload.

@view-transition { navigation: auto; }   /* opt the whole doc into cross-doc VT */

.product-card .preview { view-transition-name: arc-preview; }
.detail-hero           { view-transition-name: arc-preview; }

That second view-transition-name: arc-preview on the detail page is the match. Same name → same element from the browser's perspective, even though one is 80px and the other is 360px.
