Multi-element Three morphs at once

Each .line .pic on this page shares its view-transition-name with the matching thumbnail on the previous page. The browser morphs all three concurrently with the same timing function — no extra JS coordination needed.

.line-arc        .pic { view-transition-name: arc-preview; }
.line-battery    .pic { view-transition-name: battery-preview; }
.line-controller .pic { view-transition-name: controller-preview; }

This is what would previously have required Framer Motion's layoutId or a hand-rolled FLIP technique. The browser handles interpolation natively on the compositor thread.
