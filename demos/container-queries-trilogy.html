Size Queries

Style components based on their container's dimensions

Container size queries allow components to respond to the size of their parent container, not just the viewport. This enables true component portability and intrinsic web design.

Style Queries

Query container styles, not just dimensions

Style queries allow you to query computed styles of a container element, enabling data-driven styling without JavaScript. Currently limited to CSS custom properties.

🎨

This content adapts based on the container's --variant custom property

Current Style Query: @container style(--variant: warm)
@container style(--variant: warm) { .style-demo-content { background: linear-gradient(135deg, #fef3c7, #fde68a); color: #78350f; } } @container style(--variant: cool) { .style-demo-content { background: linear-gradient(135deg, #dbeafe, #bfdbfe); color: #1e3a8a; } }
📜

Scroll-State Queries

Detect scroll states: stuck, snapped, and scrollable

Scroll-state queries allow CSS to detect whether an element is stuck to an edge, snapped to a scroll snap point, or scrollable — eliminating the need for JavaScript scroll listeners.
