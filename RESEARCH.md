**THE 10 MiB LAW (headline — the folklore number is wrong):** "localStorage is 5MB" is wrong on two counts. Measured single-key wall: **5,243,010 characters = 10,486,020 UTF-16 bytes — 10 MiB**, byte-stable across fresh profiles. The folklore confuses **characters with bytes** — the engine accounts every key and value as **UTF-16 (2 bytes/char)**. So it is 10 MiB of *bytes* ≈ 5M *characters*. **Always measure your own quota.**
**THE OTHER-DOCUMENT EVENT LAW:** the `storage` event has a strict perimeter — **the writing document never hears its own writes.** Same-origin iframes and other tabs do. `storageArea` identifies the store; `key`/`oldValue`/`newValue` are populated (null for `clear()`). Measured: the popup saw pre-open seeds; **its writes never reached back** (`'tab-A'` stayed `'tab-A'`); the storage objects are different JS objects on both areas, in every tab. **localStorage = broadcast (all tabs, one store); sessionStorage = private copy (cloned at open).**

Split routing: non-member property writes (`localStorage.theme`) are stored as ordinary properties, NOT in the map — they vanish on reload and don't take quota.
**THE VALUE CONTRACT + ENUMERATION ORDER:** everything is coerced to a **string** (`null` → `"null"`, objects → `"[object Object]"`); `getItem` returns `null` for a missing key — indistinguishable from a stored literal `"null"`. `key(i)` follows **insertion order**; re-setting an existing key keeps its ORIGINAL slot; delete + re-add moves it to the end.
**THE WORKER JAIL:** dedicated workers have **no `localStorage`** — proxy to the main thread, or use IndexedDB/OPFS.

Every consumer joining browser-decoded audio to a timeline must skip the pre-skip and drop the tail, or drift **6.5 ms per stream start**. PCM is **ULP-exact vs ffmpeg** (max |Δ| ≈ 1.8e-7 ≈ 2⁻²³, only 25.9% of float bits coincide) — **compare with tolerance ~2⁻²², never SHA**. mp3 needs no framing (whole file from one chunk); opus needs per-packet chunks.
**State + workers:** `unconfigured → configured → closed`, `reset()` is a SOFT reset back to *unconfigured* (not configured); validation splits three ways (sync `TypeError` / `supported:false` / async `NotSupportedError` + auto-close).
