② The half-leading problem

Every font has invisible space above and below its glyphs — called half-leading. The browser splits the font's line-height into two halves and distributes them above and below the text. This means padding: 10px on a button never looks equal on all sides. Different fonts produce different amounts of half-leading, making consistent typesetting impossible — until now.

The fix is one CSS line

/* Trim both sides to the capital letter height and baseline */
.btn {
  text-box: trim-both cap alphabetic;
  padding: 10px 20px;
}

The property accepts a trim keyword (trim-start, trim-end, trim-both, none) and an edge keyword pair specifying which font metrics to trim to. The most common combo is trim-both cap alphabetic — trim the top to capital-letter height and the bottom to the alphabetic baseline.

③ The syntax — shorthand and longhands

text-box is the shorthand. Two longhands control the trim independently.

/* Shorthand — 90% of the time you write this */
.btn {
  text-box: trim-both cap alphabetic;
}

/* Longhands — for granular control */
.btn {
  text-box-trim: trim-both;  /* trim-start | trim-end | trim-both | none */
  text-box-edge: cap alphabetic;  /* over-edge under-edge */
}

/* Trim only the top (useful for headlines flush to container) */
h1 {
  text-box: trim-start cap alphabetic;
}

/* Trim to x-height instead of cap height (useful for lowercase-heavy UI) */
.badge {
  text-box: trim-both ex alphabetic;
}

/* Reset */
.default {
  text-box: normal;  /* equivalent to none auto */
}

text-box-edge values

Over edge (top)

  • text — above the ascenders
  • cap — capital letter height
  • ex — lowercase x-height
  • ideographic — CJK ideographic top
  • ideographic-ink — CJK ink top

Under edge (bottom)

  • text — below the descenders
    • alphabetic — baseline
  • ideographic — CJK ideographic bottom
  • ideographic-ink — CJK ink bottom

The most useful combos for Latin text: cap alphabetic (precise for UI), ex alphabetic (optical balance for lowercase), text alphabetic (maximum trim keeping ascenders visible).
