Section 2

The Problem: History API vs Navigation API

The History API was never designed for SPAs. It can't detect all navigation types, can't read the history stack, and popstate doesn't fire on pushState. The Navigation API fixes all of this.

Old: History API

  • Can't detect all navigations
  • popstate inconsistent
  • No history stack inspection
  • Manual link click interception
  • State only on current entry
  • No transition lifecycle
  • No abort/cancel support
  • No scroll restoration control
  • Can't traverse to arbitrary entries

✦ New: Navigation API

  • One navigate event for ALL types
  • Consistent, reliable event firing
  • Full stack via navigation.entries()
  • Automatic link/form interception
  • State on every entry
  • Transition lifecycle with promises
  • Built-in AbortSignal
  • Manual or auto scroll control
  • traverseTo(key) to any entry

Side-by-side Code

// OLD: 3 separate listeners, manual URL management
function navigate(path) {
  window.history.pushState({ path }, '', path);
  renderPage(path);  // manually render
}

window.addEventListener('popstate', (e) => {
  const path = e.state?.path || window.location.pathname;
  renderPage(path);
});

// Must manually intercept ALL link clicks
document.addEventListener('click', (e) => {
  const link = e.target.closest('a');
  if (link && link.getAttribute('href').startsWith('/')) {
    e.preventDefault();
    navigate(link.getAttribute('href'));
  }
});
// NEW: One centralized navigate event
navigation.addEventListener('navigate', (event) => {
  if (!event.canIntercept || event.hashChange) return;

  const url = new URL(event.destination.url);

  event.intercept({
    async handler() {
      await renderPage(url.pathname);
    }
  });
});

// That's it. Links, forms, back/forward — ALL covered.

Section 5

Navigation Types & Event Lifecycle

Every navigation fires the navigate event with a navigationType that tells you exactly what happened.

navigation.addEventListener('navigate', (event) => {
  switch (event.navigationType) {
    case 'push':     // New URL → new history entry
    case 'replace':  // URL replaced (no new entry)
    case 'reload':   // Page reload
    case 'traverse': // Back/forward to existing entry
  }

  // Key properties
  event.destination.url    // Target URL
  event.destination.key    // Destination entry key (traverse)
  event.destination.sameDocument  // True = SPA navigation
  event.formData           // FormData if form submission
  event.hashChange         // True = only hash changed
  event.canIntercept       // False for cross-origin
  event.downloadRequest    // True = download link
  event.userInitiated      // True = user click, not JS
  event.signal             // AbortSignal — cancels if superseded
});

The Transition Lifecycle

// intercept() creates a NavigationTransition
event.intercept({
  async handler() {
    await loadContent(url);
  }
});

// navigation.transition tracks the ongoing navigation
navigation.addEventListener('navigatesuccess', () => {
  showToast('Navigation complete ✓');
});

navigation.addEventListener('navigateerror', (e) => {
  showError('Navigation failed', e.error);

Section 6

Form Submission Without Page Reload

The navigate event catches same-document form submissions automatically. event.formData gives you the submitted data — no onsubmit needed.

navigation.addEventListener('navigate', (event) => {
  if (event.formData && event.canIntercept) {
    event.intercept({
      async handler() {
        const data = event.formData;
        const pilot = data.get('callsign');
        await registerPilot(data);
        renderDashboard(pilot);
      }
    });
  }
});

Standard HTML form — no JavaScript event handlers needed:

<form action="/register" method="POST">
  <input name="callsign" type="text" required />
  <button type="submit">Register</button>
</form>

Section 7

Async Scroll Restoration

In modern SPAs, content isn't ready when the browser tries to restore scroll position. The Navigation API gives you manual control with event.scroll().

navigation.addEventListener('navigate', (event) => {
  if (!event.canIntercept) return;

  event.intercept({
    scroll: 'manual',  // Don't auto-scroll

    async handler() {
      const data = await fetchListData();

      renderItems(data);  // DOM now has height

      event.scroll();    // NOW restore scroll position
    }
  });
});

Without this, users pressing "back" to return to a long list would land at the top — the content they were reading is off-screen. With scroll: 'manual' + event.scroll(), the scroll position is restored after the data loads.

Section 8

View Transitions Integration

The Navigation API and View Transitions API are designed to work together. Wrap your DOM updates in document.startViewTransition() during the intercept handler for app-like morphing.

navigation.addEventListener('navigate', (event) => {
  if (!event.canIntercept) return;
  const url = new URL(event.destination.url);

  event.intercept({
    async handler() {
      const content = await fetchPage(url.pathname);

      // Browser snapshots old DOM → morphs to new
      document.startViewTransition(() => {
        document.getElementById('app').innerHTML = content;
      });
    }
  });
});

Section 9

OpenDrones Mission Control Routing

Complex multi-panel SPAs benefit most from the Navigation API. Here's how OpenDrones Mission Control would use it for telemetry history navigation and mission replay.

// Mission Control: complex routing with state restoration
navigation.addEventListener('navigate', (event) => {
  if (!event.canIntercept) return;
  const url = new URL(event.destination.url);
  const segs = url.pathname.split('/').filter(Boolean);

  event.intercept({
    scroll: 'manual',
    async handler() {
      // /missions/:id → mission detail + telemetry scrubber
      if (segs[0] === 'missions' && segs[1]) {
        const mission = await api.getMission(segs[1]);
        const state = event.destination.getState() || {};

        document.startViewTransition(() => {
          renderMissionDetail(mission);
          restoreTelemetryScrubPosition(state.scrubFrame || 0);
        });
      }

      // /fleet → drone fleet grid
      if (segs[0] === 'fleet') {
        const fleet = await api.getFleet();
        document.startViewTransition(() => {
          renderFleetGrid(fleet);
        });
      }

      event.scroll();
    }
  });
});

// Save telemetry scrubber position when user scrubs through replay
function onScrubMove(frame) {
  navigation.updateCurrentEntry({
    state: { ...navigation.currentEntry.getState(), scrubFrame: frame }
  });
}

// User navigates back → scrubber restores to exact position
navigation.addEventListener('currententrychange', () => {
  const state = navigation.currentEntry.getState();
  if (state?.scrubFrame != null) {
    setTelemetryScrubFrame(state.scrubFrame);
  }
});

Section 10

Migration Guide: History API → Navigation API

STEP 1 — Add navigate listener
Add a single navigation.addEventListener('navigate', ...) handler. This replaces your popstate listener, click interceptor, and manual pushState calls.
STEP 2 — Replace pushState
Replace history.pushState() with navigation.navigate(url). Replace history.replaceState() with navigation.navigate(url, { history: 'replace' }).
STEP 3 — Use intercept()
Move your rendering logic into the intercept() handler. The browser now manages URL updates, history entries, and scroll restoration automatically.
STEP 4 — Add success/error handlers
Listen for navigatesuccess and navigateerror to centralize your error handling and loading indicators.
STEP 5 — Adopt state management
Use navigation.updateCurrentEntry({ state }) instead of history.replaceState() for UI state. Use entry.getState() to restore state on back/forward.

Common Patterns Translated

// Navigate to new page
// Old: history.pushState(null, '', '/dashboard')
// New:
navigation.navigate('/dashboard')

// Replace current entry
// Old: history.replaceState(null, '', '/login')
// New:
navigation.navigate('/login', { history: 'replace' })

// Go back
// Old: history.back()
// New:
navigation.back()

// Traverse to specific entry
// Old: impossible!
// New:
const key = navigation.entries()[2].key;
navigation.traverseTo(key)

// Update state without navigation
// Old: history.replaceState({...}, '')
// New:
navigation.updateCurrentEntry({ state: { scrollY: 420 } })
