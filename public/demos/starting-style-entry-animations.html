CSS @starting-style

Entry & Exit Animations
Without JavaScript

Animate elements appearing, disappearing, and transitioning to/from the top layer — all in pure CSS.

1. Animated Popover

Popovers animate in from below with opacity + scale, exit upward. Uses @starting-style inside :popover-open.

Battery Status

The Arc 3000mAh pack is fully charged and ready for flight. Estimated runtime: 12 min.

/* Exit state — default */ [popover] { opacity: 0; transform: translateY(-10px) scale(0.95); transition: opacity 0.3s, transform 0.3s, display 0.3s allow-discrete, overlay 0.3s allow-discrete; } [popover]:popover-open { opacity: 1; transform: translateY(0) scale(1); @starting-style { opacity: 0; transform: translateY(10px) scale(0.9); } }

2. Notification Toasts

Elements slide in from the right with height animation. Exit animates out. @starting-style provides the "before-open" state.

.toast { transition: opacity 0.4s, transform 0.4s, height 0.4s, display 0.4s allow-discrete; opacity: 1; transform: translateX(0); @starting-style { opacity: 0; transform: translateX(100%); height: 0; } }

3. Dialog Modal

Modals scale + fade in from below with a custom cubic-bezier. Backdrop fades separately. Both use @starting-style.

Confirm Order

Are you sure you want to add The Arc battery pack to your cart? This will start the checkout process.
dialog { opacity: 0; transform: scale(0.85) translateY(20px); transition: opacity 0.35s cubic-bezier(0.16,1,0.3,1), transform 0.35s cubic-bezier(0.16,1,0.3,1), display 0.35s allow-discrete, overlay 0.35s allow-discrete; } dialog[open] { opacity: 1; transform: scale(1) translateY(0); @starting-style { opacity: 0; transform: scale(0.85) translateY(30px); } } dialog::backdrop { background: rgba(0,0,0,0.7); transition: opacity 0.35s, display 0.35s allow-discrete; opacity: 1; @starting-style { opacity: 0; } }

4. Animated List (Add/Remove)

Items slide in from above on add, skew + slide left on remove. The classic TODO pattern — zero JS animation libraries needed.

.list-item { transition: opacity 0.4s, transform 0.4s, height 0.4s, display 0.4s allow-discrete; opacity: 1; transform: translateX(0); @starting-style { opacity: 0; transform: translateY(-10px); height: 0; } } .list-item.is-deleting { opacity: 0; transform: translateX(-100%) skewX(10deg); height: 0; display: none; }

Key Takeaways

  • Three states: @starting-style (entry), open state, exit state
  • Asymmetric animations: Enter from bottom, exit to top — different easing per direction
  • Works with: Popovers, dialogs, display:none toggles, dynamically added DOM nodes
  • Required combo: transition-behavior: allow-discrete to animate display and overlay
  • Browser support: Chrome 117+, Safari 17.4+, Firefox 128+ — Baseline 2025
  • Zero JavaScript needed for the animation logic itself
