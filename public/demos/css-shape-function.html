2. shape() vs path() — The Responsive Revolution

Both produce the same flag shape. But only shape() uses CSS units (% , px, calc, var) and stays responsive when the element resizes.

clip-path: path()

Fixed pixel coordinates. Breaks on resize. SVG path syntax — not human-readable.

clip-path: shape()

CSS-native units — %, px, calc(), var(). Fully responsive. Animatable via @property.
/* path() — fixed pixels, no responsiveness */ .flag { clip-path: path("M 0 20 C 25 0 75 40 100 20 V 80 C 75 100 25 60 0 80 z"); } /* shape() — CSS units, responsive, animatable */ .flag { clip-path: shape(from 0% 20%, curve to 100% 20% with 25% 0% / 75% 40%, vline to 80%, curve to 0% 80% with 75% 100% / 25% 60%, close ); }

6. Animated Shapes via @property

Register custom properties with @property, then animate them. shape() coordinates update smoothly — impossible with path().

Morphing wave — @property drives shape() coordinates
@property --wave-h { syntax: "<length>"; inherits: false; initial-value: 20px; } @keyframes morph { from { --wave-h: 5px; } to { --wave-h: 40px; } } .flag { animation: morph 2s ease-in-out infinite alternate; clip-path: shape(from 0% var(--wave-h), …); }

10. Full Command Reference

Every shape() command, what it does, and its syntax.

from <x> <y>
Starting point. Coordinates relative to reference box.
from 0% 0% · from 10px 50% · from center
move [by|to] <x> <y>
Move without drawing. Start a new subpath.
move to 50% 50% · move by 20px 0
line [by|to] <x> <y>
Straight line to a point. by = relative, to = absolute.
line to 100% 100% · line by 50px 0
hline / vline [by|to] <val>
Horizontal or vertical line. Single axis value only.
hline to 100% · vline by 50px
curve [by|to] <x> <y> with <cp1> [/ <cp2>]
Bézier curve. One control point = quadratic, two = cubic.
curve to 100% 50% with 50% 0% · curve to 80% 80% with 20% 0% / 60% 100%
smooth [by|to] <x> <y> [with <cp>]
Smooth Bézier — reflects previous curve's control point. C¹ continuous.
smooth to 100% 50% · smooth to 90% 10% with 50% 0%
arc [by|to] <x> <y> of <rx> [<ry>] [cw|ccw] [large|small] [rotate <angle>]
Elliptical arc. Radius, sweep direction, size, rotation.
arc to 80px 50% of 40px ccw large · arc to 100% 100% of 50% 50%
close
Close the path. Line back to the start of the current subpath.
close
[nonzero|evenodd]
Optional fill rule. Placed before from. Controls overlapping shape fills.
shape(evenodd from 0 0, …) · shape(nonzero from 0 0, …)

12. Decision Matrix — shape() vs path() vs polygon()

When to reach for each clipping method.

Curved shapes that must resize — hero blobs, wave dividers, organic UI
shape()
Simple straight-line polygons — arrows, hexagons, triangles
polygon()
Pixel-perfect SVG paths — fixed-size icons, logos from design tools
path()
Animated morphing shapes — @property + clip-path animation
shape()
Basic geometric clips — circles, ellipses, inset rectangles
circle() / inset()
Motion paths for animation — drone flight, particle trajectories
shape()
Complex SVG-origin paths — imported from Figma/Illustrator, fixed size
path()

14. Recap & Stack Composition

Why shape() matters now

  • Baseline 2026 — all three major browsers shipped. ~93% global traffic.
  • The first clip-path primitive that accepts CSS units — %, px, em, calc(), var()
  • Pairs with @property for smooth morphing animations — zero JS
  • Pairs with offset-path for responsive motion paths — zero SVG
  • Replaces PNG/SVG decorative assets with pure CSS — fewer HTTP requests
  • Composes with @starting-style for entry animations on clipped elements
  • Future: border-shape property will bring these shapes to borders (CSS Borders 4)

Pairs with the documented stack

  • @property (P1) — animated custom properties drive shape() coordinates
  • View Transitions (P2) — morph between shape() clips during page transitions
  • Scroll-Driven Animations (P2) — scroll-triggered shape reveals
  • Container Style Queries (P2) — component variants change clip shape
  • contrast-color() (P3) — readable text inside any shape
  • Custom Highlight API (P1) — highlight inside shaped containers
