CSS shape() Function

Responsive, CSS-native complex shapes for clip-path and offset-path. Replace fragile SVG path strings with readable, animatable, percentage-based CSS commands.

⚠️ Your browser does not support shape() yet. Shapes will appear as unclipped rectangles. Try Chrome 135+ or Safari 18.4+.

🔥 The Problem It Solves

Before shape(), creating complex non-polygon shapes in CSS meant using SVG path() — pixel-locked, non-responsive, and unreadable. You had to choose between responsive but simple (polygon, circle) or complex but fixed-size (SVG path).

❌ Before: path()

clip-path: path("M 0 20 C 25 0 75 40 100 20 V 80 C 75 100 25 60 0 80 z");

• Pixel units only — breaks on resize
• SVG syntax — not CSS-native
• Can't use calc(), var(), or %
• Can't animate individual values

✅ After: shape()

clip-path: shape(from 0% 20%,
  curve to 100% 20% with 25% 0% / 75% 40%,
  vline to 80%,
  curve to 0% 80% with 75% 100% / 25% 60%,
  close
);

• Percentage units — scales with element
• CSS-native syntax — readable
• Supports calc(), var(), @property
• Animatable via @property
