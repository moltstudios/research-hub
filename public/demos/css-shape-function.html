Section 2

shape() vs path() — Why a New Function?

path() accepts only unitless SVG syntax. shape() accepts percentages, calc(), var(), and all CSS units — making shapes responsive for the first time.

path() — Rigid
  • Unitless numbers only (SVG px)
  • No percentages
  • No var() or calc()
  • Not responsive
  • Single string, no composition
shape() — Responsive
  • All CSS units (px, %, rem, em)
  • Percentages scale with element
  • calc(), var(), sin(), cos()
  • Fully responsive — resize friendly
  • Named commands, readable

Superset: Every path() can be converted to shape(), but not vice-versa. Tools like SVG to CSS Shape converter automate the migration.

Section 4

Shape Commands — The Full API

Eight commands cover every shape from rectangles to complex Bézier curves. Each supports both to (absolute) and by (relative) positioning.

from x y
Starting point. Required first command. Accepts keywords (top, center, bottom left) or coordinates.
shape(from 50% 0%, …)
line [by|to] x y
Straight line to the next point. to = absolute from origin, by = relative to previous command.
shape(from 0 0, line to 100% 100%)
hline / vline [by|to] val
Horizontal or vertical line. Only one coordinate needed — the other stays from the previous point.
shape(from 0 0, hline to 100%, vline to 100%, hline to 0)
curve [by|to] x y with cx cy
Bézier curve. One control point = quadratic; two (separated by /) = cubic. Control points support from start|end|origin keyword.
shape(from 0 0, curve to 100% 0 with 50% -20%)
smooth [by|to] x y [with cx cy]
Smooth Bézier that auto-reflects the previous curve's control point. Omit with for quadratic smooth; include for cubic smooth.
shape(from 0 0, curve to 50% 0 with 25% -10%, smooth to 100% 0)
arc [by|to] x y of rx ry [cw|ccw] [large|small] rotate Ndeg
Elliptical arc. of sets radii. cw/ccw = direction (default ccw). large/small = arc size (default small). rotate tilts the ellipse.
shape(from 0 0, arc to 100% 0 of 50% 50% cw small)
move [by|to] x y
Move without drawing. Creates sub-paths or repositions for the next command. Useful for multi-part shapes (donut holes, cut-outs).
shape(from 0 0, line to 100% 0, move to 50% 50%, close)
close
Draw a straight line back to the from point. Closes the shape. Required for a complete clip-path.
shape(from 0 0, hline to 100%, vline to 100%, close)

/* Blob — pure percentages, scales with container */ .blob { clip-path: shape( from 25% 0%, curve to 75% 0% with 50% 10%, curve to 100% 50% with 90% 40%, curve to 50% 100% with 100% 90%, curve to 0% 50% with 10% 90%, curve to 25% 0% with 0% 40% ); } /* With var() and calc() — parametric radius */ .card { --r: 20px; clip-path: shape( from calc(var(--r)) 0, hline to calc(100% - var(--r)), arc by calc(var(--r) * 2) 0 of var(--r) cw, vline to 100%, hline to 0 ); }

Motion Paths — Animate Along shape() Curves

offset-path: shape(...) makes elements travel along custom curves. No JS, no GSAP, no SVG path animation libraries. Pure CSS motion.

2 objects · 2 offset-paths · 0 lines of JavaScript
/* Object follows a Bézier curve path */ .object { offset-path: shape( from 10% 80%, curve to 90% 20% with 30% 10%, curve to 50% 50% with 90% 50%, curve to 10% 80% with 70% 50% ); offset-rotate: auto; animation: travel 4s cubic-bezier(0.4, 0, 0.2, 1) infinite; } @keyframes travel { from { offset-distance: 0%; } to { offset-distance: 100%; } }
