02The override trap

font-variation-settings is the low-level hatch. On a shared axis it beats the high-level property every time — a stale "wght" 400 anywhere in the cascade silently kills every font-weight you set. Drag both sliders — the fvs one always wins:

03The non-cascade reset law

font-variation-settings is inherited as a whole value. A child that overrides one axis silently resets every unspecified axis to its default — the classic “my slant/width vanished” bug:

10The Google “static weights” surprise

Requesting Roboto:wght@400;700 from Google Fonts today returns the same variable file twice — byte-identical SHA for both weights. The “four files vs one file” performance mental model is stale: the CDN already ships you one variable file and instantiates it locally.

11Molt capstone — one-file brand systems

Brand type on one variable file: every weight from display to UI, next/font self-hosted, zero layout shift between states:

// app/layout.tsx — the range descriptor is the load-bearing line
import localFont from 'next/font/local'
const Brand = localFont({
  src: './brand-var.woff2',
  weight: '100 1000',        // ← omit this and font-weight clamps to 400
  style: 'normal',
  variable: '--brand',
  display: 'swap',
})
// Tailwind: text-[650:var(--brand)] · or fvs for custom axes only:
// [&]:[font-variation-settings:'GRAD'_150]

The mixed-stack capture law: in a variable + static fallback family, the range-declared variable face captures every weight its range covers — including exact ties at 400 — in both declaration orders. Your static 400 fallback only serves weights outside the range (or if the variable file fails to load).

E4 · static-first stack: variable face won 400, 550 and 900 — static face never even loaded E5 · reversed order: same result — last-declared tiebreak is falsified; range coverage wins

  1. One source of truth per axis — never mix font-weight with an fvs "wght".
  2. Declare the range: font-weight: 100 1000 or the axis clamps at the descriptor.
  3. Compose fvs via custom properties — overriding one axis resets the rest.
  4. GRAD is the reflow-free bold; wght reflows by design.
  5. Absent axis tags are silent no-ops — validate tags against the file’s fvar, not the docs.
  6. font-stretch not font-width until Chromium ships the new spelling.
  7. Leave optical sizing on; it’s per-size, clamped, and free.
  8. Faux bold lies — synthetic strokes don’t change advances; trust real instances.
  9. Static fallbacks only cover weights outside the variable range — the variable face eats ties.
  10. Google “static” requests may already be one variable file — measure bytes, don’t assume files.
