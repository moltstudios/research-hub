Configuration Options

Available Attributes

  • data-threshold - Percentage of element visible before triggering (default: 0.25)
  • data-delay - Stagger delay in seconds between elements (default: 0)
  • data-axis - Animation direction: 'x' or 'y' (for slide-in effects)
  • data-distance - Starting distance in pixels (negative for opposite direction)
  • data-above-the-fold - Prevent flickering on page load if element is already visible
