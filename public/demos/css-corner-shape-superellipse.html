5 · THE OLD WAY vs THE NEW WAY From 3 files + 1KB mask → 1 line of CSS

End of the 1MB SVG squircle mask hack.

For a decade the only way to ship a true iOS-style squircle on the web was a 3-file system: an SVG mask template, a CSS clip-path that referenced it, and per-asset tuning of the mask offset. corner-shape eliminates all three.

The old way · SVG mask1KB · 3 files · per-asset tuning
// squircle.svg — asset shipped per radius <svg> <clipPath id="squircle-32"> <path d="M32,0 C49,0 64,15 64,32 ...superellipse math here..." /> </clipPath> </svg> /* main.css */ .avatar { clip-path: url(#squircle-32); -webkit-clip-path: url(#squircle-32); /* border, focus-ring, mask-offset all break */ }
The new way · pure CSS1 line · 0 assets · 0 tuning
/* main.css — one line, ships with the element */ .avatar { border-radius: 32px; corner-shape: squircle; /* borders, focus rings, mask offsets all just work */ } /* Or parameterize the squircle exponent */ .avatar-bolder { border-radius: 40px; corner-shape: superellipse(2); }

Why it matters beyond aesthetics

The old SVG-mask squircle hack broke three things corner-shape preserves:

  • Border + focus ring. clip-path clips the border away. corner-shape curves the box itself, so border, outline, box-shadow, and focus-visible all render natively.
  • Sub-pixel precision. SVGs scale; corner-shapes compute at the device pixel grid. No more 0.5px mask offset artifacts on Retina.
  • Zero asset budget. One CSS rule replaces a 1KB SVG file per radius size. Molt saves ~50KB across a 5-radius design system.

7 · RECAP & SHIP PLAN Why P4 · what to ship today · next steps

The 30-second summary — why P4, what to ship.

WHAT

Native superellipse & squircle curves

corner-shape with 8 built-in values (round, squircle, superellipse(n), bevel, notch, scoop) plus tunable superellipse(-5 → 10) exponent. Replaces the 1MB SVG mask hack.

WHY P4

High-impact polish primitive

Not P1 — only ~74% support. Not P2 — does not ship today for every client without a fallback. P4 — exactly the right altitude for a "ship with one-line fallback" upgrade that visually elevates every Molt deliverable and every OpenDrones telemetry surface.

MOLT FIT

Pure CSS squircle per client brand

Apple-clients get squircle. Tech-startup clients get superellipse(2). Industrial clients get bevel. One CSS custom property per brand re-skins every rounded container on the site.

OPENDRONES FIT

Mission Control v2 telemetry grid

Every telemetry card uses superellipse(3.5). Stat boxes use superellipse(2.5). Status pills use superellipse(4). One CSS file ships the entire visual upgrade.

FALLBACK

3-line safe-ship pattern

@supports (corner-shape: round) wraps the new shape; everything else sees the original border-radius. Zero breakage. Zero layout shift. Graceful degradation that already looks correct.

NEXT

WebKit + Firefox interop push

Safari TP already has it. Firefox 152+ is behind a flag. CSSWG resolved the spec at TPAC 2025. Track Interop 2027 — likely a focus area alongside if(), reading-flow, and the @scope refinement.
