LAW 01 — THE SILENT ZERO

A missing quiet zone reads as “no barcode”

If a 1D barcode touches the image edge, the engine returns an empty array — no error, no warning. The exact same pixels with a white ring around them decode instantly. Left bar has zero padding; right bar gets a 14px white ring.

LAW 02 — THE ALPHA WALL

Transparent backgrounds are invisible

Most QR generators (and every react-qr-code default) emit black modules on a transparent background. The engine treats alpha-0 as dark — the whole image is one black rectangle. Composite over opaque white and it decodes.

LAW 03 — THE HINT IS ADVISORY

Unknown formats don’t filter. Known ones do.

The constructor’s formats option only filters by formats the engine actually supports. Ask for ['codabar'] (not in the menu) and the detector happily finds a QR code — the unknown name is silently dropped. Ask for ['code_128'] and a QR becomes invisible. Empty array? LAW 07 — THE CROP CLIFF

Crop into the quiet zone and it dies

Quiet-zone starvation from the other side: this QR wears a 20px white ring. At 12% the white ring is eaten but the QR’s own 2-module margin keeps it alive. LAW 08 — ORDER IS NOT SPACE

Multi-detection returns engine order

Three codes, one canvas. A human reads left-to-right: QR, Code 128, EAN. The engine returns its own order — deterministic per input, but not spatial. Never z-sort assumptions; use boundingBox.x.

LAW 09 — THE PATIENCE RULE

detect() waits for images that are still loading

Hand it an <img> whose bytes haven’t arrived and the result is a coin-flip: measured over HTTP it waited and decoded; measured with an instant blob URL it threw InvalidStateError: “Failed to load or decode.” The rule: never race it — await img.decode() first. A 404’d image is a guaranteed InvalidStateError.

LAW 10 — THE SECURITY PERIMETER

Two invisible walls

Cross-origin images without CORS throw SecurityError: “Source would taint origin” — even when you never touch a canvas. And on plain-HTTP non-localhost origins the whole class vanishes (typeof BarcodeDetector === 'undefined'). Surprise on macOS Chromium: file:// pages are a secure context — the API is there.
