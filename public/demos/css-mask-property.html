4. Hover Reveal Animations

The killer pattern from Smashing Magazine — a single element, no extra markup, using mask-composite: exclude to create cutout reveal effects on hover. The mask shrinks/grows to reveal or hide content.

Circle Reveal
Diagonal Wipe
Pixel Dissolve
/* Circle reveal — mask-composite: exclude creates a hole */ .tile { padding: 2px; /* border thickness */ background: linear-gradient(135deg, #7c5cfc, #ff6b9d); -webkit-mask: linear-gradient(#000 0 0), radial-gradient(#000 70%, #0000 71%) content-box 50% / 150% 150% no-repeat; mask-composite: exclude; /* standard */ -webkit-mask-composite: xor; /* Chromium */ transition: .5s; } .tile:hover { -webkit-mask: linear-gradient(#000 0 0), radial-gradient(#000 70%, #0000 71%) content-box 50% / 0% 0% no-repeat; /* shrink circle → reveal */ mask-composite: exclude; -webkit-mask-composite: xor; } /* Diagonal wipe — slide mask position */ .diagonal { -webkit-mask: linear-gradient(#000 0 0), linear-gradient(135deg, #000 50%, #0000 0) content-box 0% 0% / 200% 200% no-repeat; mask-composite: exclude; -webkit-mask-composite: xor; transition: .5s; } .diagonal:hover { -webkit-mask-position: 0% 0%, 100% 100%; } /* Pixel dissolve — repeating-conic-gradient mask */ .pixel { -webkit-mask: repeating-conic-gradient(#000 0 25%, transparent 0 50%) 0 0 / 20px 20px; transition: .5s; } .pixel:hover { -webkit-mask-size: 0 0; /* dissolve all pixels */ }

7. Scroll-Driven Mask Wipe

Pair mask with animation-timeline: view() (scroll-driven animations) to create wipe reveals as elements enter the viewport. Zero JavaScript.

↑ This bar wipes from left to right as you scroll past it. The mask animates via animation-timeline: view() — no scroll listener, no JS.

.reveal-bar { animation: wipe-reveal linear; animation-timeline: view(); } @keyframes wipe-reveal { from { -webkit-mask: linear-gradient(to right, #000 0%, transparent 0%); mask: linear-gradient(to right, #000 0%, transparent 0%); } to { -webkit-mask: linear-gradient(to right, #000 100%, transparent 100%); mask: linear-gradient(to right, #000 100%, transparent 100%); } }

The -webkit- prefix reality

For production, always include both -webkit-mask and mask. Safari required the prefix until 15.4 and the Blink engine still uses -webkit-mask-composite with different keyword names (xor, source-over, source-in, source-out) vs the standard (exclude, add, intersect, subtract). Include both for full compat.

Why P2 (not P1, not P3)

  • Not P3 — Baseline Widely Available, ~97% traffic, directly applicable to every client project and OpenDrones HUD.
  • Not P1 — While powerful, mask is a visual enhancement, not a functional requirement. Sites work without it. The P1 entries (Anchor Positioning, Highlight API, Subgrid, @property) are structural primitives that change how you build.
  • Yes P2 — Ship-today visual primitive with broad browser support. Composes with scroll-driven animations, view transitions, and the entire modern CSS toolkit. Direct production value for both Molt Studios ($3k-8k visual upgrade packages) and OpenDrones (HUD overlay system).
