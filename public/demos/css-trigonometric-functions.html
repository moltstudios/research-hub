01 The Fundamental Formula

Everything in this demo builds on two lines of math. To place a point on a circle of radius r at angle θ:

/* x = r × cos(θ), y = r × sin(θ) */
.dot {
  --angle: 45deg;
  --r: 120px;
  translate: calc(cos(var(--angle)) * var(--r))
                  calc(sin(var(--angle)) * var(--r));
}

Drag the slider to see cos() (adjacent), sin() (opposite), and the point update in real time. The hypotenuse is the radius line — its length is always r.

02 Pure CSS Analog Clock

Three hands positioned with sin() and cos(). The second hand animates via @property + CSS animation. The hour and minute hands update from JS-set custom properties (CSS can't read the system clock — yet — but the positioning math is pure CSS trig).

/* Each hand positioned with trig */
.clock-hand {
  position: absolute;
  top: 50%; left: 50%;
  transform-origin: center bottom;
  transform: translate(-50%, -100%) rotate(var(--angle));
}

04 Sun Position Arc — Golden Hour Mission Planning

For drone photography missions, sun position determines shadow length and golden-hour timing. The sun's position is a single --sun-angle custom property — CSS cos() places it horizontally, sin() sets the height. Shadow direction is the inverse.

EAST ↑ WEST ↑ 
/* θ = 0° → sunrise (east horizon), θ = 90° → noon (zenith), θ = 180° → sunset (west) */
.sun-body {
  --r: 180px;
  translate: calc(cos(var(--sun-angle)) * var(--r) - 50%)
                  calc(sin(var(--sun-angle)) * var(--r) * -1); /* negative = up */
}

05 Compass Rose with sin()/cos() Tick Marks

Every tick mark on this compass is positioned and rotated using CSS trigonometry. The 36 minor ticks (every 10°) and 8 major ticks (every 45°) are pure CSS — zero SVG, zero JavaScript.

/* 36 ticks generated with --i, positioned with sin/cos */
.compass-tick {
  --angle: calc(var(--i) * 10deg);
  --r: 130px;
  position: absolute;
  top: 50%; left: 50%;
  translate: calc(cos(var(--angle)) * var(--r) - 50%)
                  calc(sin(var(--angle)) * var(--r) - 50%);
  rotate: var(--angle);
}

07 Orbit Animation with @property

Six dots orbiting at two radii. The @property --orbit-angle registration lets CSS animate interpolate the angle — combined with sin()/cos() in translate, this produces smooth orbital motion. Each dot's delay is offset by --i to distribute them around the ring.

⭐
@property --orbit-angle {
  syntax: '<angle>';
  inherits: false;
  initial-value: 0deg;
}
.orbit-dot {
  translate: calc(cos(var(--orbit-angle)) * var(--r))
                  calc(sin(var(--orbit-angle)) * var(--r));
  animation: orbit-spin 4s linear infinite;
  animation-delay: calc(var(--i) * -0.5s);
}
@keyframes orbit-spin { to { --orbit-angle: 360deg; } }

08 Spiral Layout — Radius Grows with Index

Same formula, but --r increases per dot. This creates an Archimedean spiral — pure CSS, 24 dots, each one positioned by --i alone. The color cycles through HSL using the same index.

.spiral-dot {
  --angle: calc(var(--i) * 30deg);
  --r: calc(6px + var(--i) * 4px);  /* grows! */
  --x: calc(cos(var(--angle)) * var(--r));
  --y: calc(sin(var(--angle)) * var(--r));
  translate: calc(var(--x) - 50%) calc(var(--y) - 50%);
  background: hsl(calc(var(--i) * 11), 80%, 60%);
}

09 atan2() — Point Elements at a Target

atan2(y, x) computes the angle from one point to another. Move your mouse over the box — the arrow rotates to point at your cursor, and the four corner boxes each calculate their angle independently. This is the foundation for tooltip direction, connector lines, and "face the camera" UI.

10 Wave / Equalizer Pattern

40 bars animated by sin(). Each bar's height is a sine wave offset by its index — the classic audio equalizer / radar pulse effect. No requestAnimationFrame, no Canvas, no WebGL. Pure CSS animation on a registered angle property.

@property --wave-angle { syntax: '<angle>'; inherits: true; initial-value: 0deg; }
.wave-bar {
  --angle: calc(var(--i) * 12deg);
  height: calc(50% + sin(var(--wave-angle) + var(--angle)) * 40%);
  animation: wave-flow 2s ease-in-out infinite;
}

11 The Complete Function Set

cos(θ)angle-1 to 1X-axis position on circle
tan(θ)angle-∞ to +∞Slope calculation, projection lines
asin(v)-1 to 1angleFind angle from sine value
acos(v)-1 to 1angleFind angle from cosine value
atan(ratio)numberangleFind angle from tangent
atan2(y, x)two numbersanglePoint element at target — the killer function

Unlike their JavaScript counterparts, CSS sin() and cos() accept both radians and degrees — sin(45deg) and sin(0.7854rad) are equivalent. This is a small but joyful ergonomic improvement over Math.sin() which requires radian conversion.
