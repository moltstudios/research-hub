💻 Implementation Code

app/globals.css CSS 
/* Define adaptive color tokens */
:root {
  --bg-primary: light-dark(#ffffff, #0a0a0f);
  --bg-secondary: light-dark(#f8f9fa, #12121a);
  --text-primary: light-dark(#212529, #e8e8f0);
  --text-secondary: light-dark(#6c757d, #adb5bd);
  --border: light-dark(#dee2e6, #2a2a42);
  --accent: light-dark(#7c6aff, #6a5aff);
  --accent-soft: light-dark(#e8e8ff, #2a2a4e);
}

/* Use in your components */
body {
  background: var(--bg-primary);
  color: var(--text-primary);
  transition: background 0.3s ease, color 0.3s ease;
}

.card {
  background: var(--bg-secondary);
  border: 1px solid var(--border);
  border-radius: 12px;
  padding: 1.5rem;
}

.card h2 {
  color: var(--accent);
}

.card p {
  color: var(--text-secondary);
  line-height: 1.6;
}

📊 light-dark() vs Old Approaches

❌ Old Approach (CSS Custom Properties)
~50 lines
Define --bg-light and --bg-dark, toggle class on html, add transition. Requires JavaScript or media query. Complex.
✅ light-dark() Function
~1 line
Define --bg: light-dark(#fff, #000). Automatic. No JavaScript. Browser-managed.
